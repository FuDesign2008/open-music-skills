# 显式内容检查器（explicit-checker）

> **定位**：分发前的合规检查。发现显式内容后标记，不自动修改。
> **适用范围**：项目中的歌词文件（单曲或整张专辑）；目标分发平台以项目配置为准，下文平台仅为示例。

---

## 触发词

- **显式内容 / 检查敏感词 / 审核歌词 / 敏感词扫描**：扫描歌词中的中英文敏感词
- **explicit**：英文触发
- **发布前检查**：分发前合规扫描

## 英文显式内容词表

以下词汇及变体需要标记 `Explicit: Yes`：

| 类别 | 词汇 |
|------|------|
| **F-word** | fuck, fucking, fucked, fucker, motherfuck, motherfucker |
| **S-word** | shit, shitting, shitty, bullshit |
| **B-word** | bitch, bitches |
| **C-words** | cunt, cock, cocks |
| **D-word** | dick, dicks |
| **P-word** | pussy, pussies |
| **A-word** | asshole, assholes |
| **歧视性词汇** | whore, slut, n-word, f-word (slur) |
| **亵渎** | goddamn, goddammit |

**不需要标记的词汇**：damn, hell, crap, ass, bastard, piss

> 注意：「damn」单独出现不需要标记，但「goddamn」需要标记。

## 中文敏感词表

以下类别在歌词中出现时需要在元数据中标记，并在分发时注意平台规则。分两档处理：**A 档 → 标记 `Explicit: Yes`**（海外平台合规）；**B 档 → 国内平台拒审风险**，建议创作阶段规避。

| 类别 | 档位 | 代表词（非穷举） | 检测要点 |
|------|------|----------------|---------|
| **粗口/脏话** | A | 操、妈的、卧槽、他妈、傻逼、贱、滚蛋 | 含谐音变体（草/cao、tmd、sb、煞笔） |
| **性相关** | A+B | 直白性行为/性器官描写词汇 | 含露骨隐喻、谐音替写；国内平台尤敏感 |
| **暴力/血腥** | A | 具体暴力行为描写（如砍杀、爆头、捅、虐杀） | 区分文学意象（如「斩王」）与露骨描写 |
| **毒品** | A+B | 具体毒品名称、吸食行为描写 | 国内平台直接拒审 |
| **歧视性用语** | A+B | 种族、性别、地域、残障歧视词汇 | 含地域黑、性别蔑称 |
| **政治敏感** | B | 涉政治人物、事件、组织的敏感内容 | 国内平台高风险，可能直接拒绝上架 |

**检测方法**：
1. 逐行扫描上表代表词及其**谐音/拆字/字母缩写变体**（中文规避手段常见）
2. 结合**语境**判断：文学意象（如玄幻题材的「斩」「血」）与露骨描写应区别对待——拿不准时标记并提示用户决策
3. A 档命中 → 建议 `Explicit: Yes`；B 档命中 → 额外提示「国内平台拒审风险」

> ⚠️ 本表为代表性框架，非穷举词典。具体词汇随创作题材持续补充；露骨程度与语境判断属软指南，最终标记由创作者决策。

## 工作流

### 单曲目检查

1. Read 目标歌词文件
2. 定位歌词段落
3. 逐行扫描中英文敏感词（大小写不敏感）
4. 检查变体形式（英文：fucking/fucked/fucker；中文：同义词/谐音替代）
5. 对比文件中是否已有 `Explicit: Yes/No` 标记
6. 生成报告

### 整张专辑检查

1. 收集专辑目录下全部歌词文件
2. 逐首扫描
3. 汇总专辑级别的显式标记判断

## 标记不匹配处理

### 标记为 No 但内容含有显式词
```
⚠️ 不匹配：曲目含有显式内容但 Explicit 标记为 "No"
操作：设置 Explicit: Yes
```

### 标记为 Yes 但内容 Clean
```
ℹ️ 提示：曲目标记 Explicit 但未发现显式词汇
这是可接受的——创作者可能因主题/语境需要标记
无需操作（保守标记没问题）
```

## 分发平台要求

> 若项目未指定目标分发平台：先向调用者确认平台配置，不假定单一平台规则；平台审核口径以官方文档为最终依据。

### 海外分发平台（DistroKid / TuneCore / CD Baby 等）
- **曲目级标记**：每首必须标记 Explicit 或 Clean
- **专辑级标记**：任一首 Explicit 则整张专辑为 Explicit
- **元数据一致性**：标记必须与实际内容匹配
- **标记错误的后果**：显式内容标 Clean → 可能被平台下架、账号受限；Clean 标 Explicit → 减少播放列表曝光但无处罚

**原则**：拿不准就标 Explicit。漏标比过标更严重。

### 国内平台（汽水音乐 / 抖音等）
- 审核标准更严格，敏感词范围更广
- 涉及政治敏感、色情、暴力的内容可能直接拒绝上架
- 建议在创作阶段就注意歌词内容合规

**生成合规前置建议**：若平台内容审核拒绝（如「内容暂不支持生成」「当前内容不符合平台规范」），**首次拒绝即弃**——不重试、不定位触发词、不代改词（再创作方向由创作者决定）；同一作品累计 3 次失败即弃（跨会话累计）。因此 B 档命中应在生成前即呈报创作者改词决策，避免撞审核白烧生成额度。

> 以上规则以项目实际配置的目标平台为准；平台名单与审核口径变化时，以平台官方文档为最终依据。

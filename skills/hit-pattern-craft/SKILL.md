# 爆款模式 craft（hit-pattern-craft）

> **定位**：企划/写词/定曲名/发行前的定位与自查 craft——先用数据回答「这首曲子走哪条流量路径」，再对照性状库逐条自查，最后按发行配套落地。是创作链（imagery/story/whitespace/orchestration 管单维度技法）之外的**定位与性状维度**。
> **数据观**：性状库是**活的**——每批发行后回喂验证，按实证增删；相关性不等于因果，平台机制以目标平台当前规则为准。

---

## 第一步：流量路径定位（写词前必答）

> 两条路径对创作的指向不同，**混做=两头不靠**。每首曲子企划时先选路径。

| | 路径 A：推荐池氛围曲 | 路径 B：UGC 钩子曲 |
|---|---|---|
| **流量来源** | 平台站内推荐池/歌单收录（起量→达峰→衰减） | 用户投稿/二创使用→外溢回站内搜索（不保证回流） |
| **曲子形态** | 氛围统一、意象连贯、成组发行 | 15 秒情绪钩子锋利、可截取传播 |
| **词作指向** | 意象流动、画面连贯、抒情密度均匀 | 反差句式 + 极简 Bridge + 气声 outro（钩子段醒目） |
| **成功判据** | D2-D3 观察；进池参考线按同层比较 | 投稿量/站外热度作为观察参考，不与站内结算挂钩 |

> **平台边界**：不同平台的推荐/投稿机制不同；「站外火→站内涨」不保证成立（跨引擎相关性可能接近零）。路径规划以目标平台当前规则与自身数据为准。

**定位问题（企划时逐首回答）**：
1. 这首曲子若 72 小时无人使用，靠什么活？（推荐池收录→路径 A）
2. 若做钩子段，哪 15 秒会被用户选中？（有明确答案→路径 B）

两个都能答 = 双路径曲（最优）；只能答 1 = 路径 A；只能答 2 = 路径 B；都答不出 → 回企划重审。

**双路径曲配方**：路径 A 的氛围统一 + 路径 B 的钩子段——**氛围底色做 A，副歌做 B**。

## 第二步：性状库 15 条（写词中对照自查）

> 每条来自爆款解构与双案例验证。**逐条对照，标注命中/缺口，不必全占**——一批三首占 8-10 条即达标线。

### 路径 B 钩子性状（1-6）

1. **反差钩子句式**：「只想 X / 为什么非要我 Y」——普通愿望 vs 被迫命运。
2. **双清单结构**：想要的（名词 + 光，私人极简）vs 被强加的（动词 + 金属，宏大暴力）。
3. **意象反转**：美丽物 = 武器，平凡物 = 奢侈品。
4. **拒绝标签句式**：「X 是别人说的 / Y 也是别人叫的」。
5. **极简 Bridge**：名词清单 +「仅此而已」式收束。
6. **衰减式收尾**：Final Chorus 一句 + 气声轻叹 outro。

### 路径 A 氛围性状（7-10）

7. **民乐/标志音色开场 5 秒进主题**——东方美学锚定 + 完播率。
8. **宿命感音色配方**：慢板 68-76 BPM + 小调 + 特色音程（小二度）。
9. **四段情绪曲线**：克制→宿命渐重→绚烂爆发→轻叹归寂。
10. **曲名 = 高搜索词**：成语/熟语/名句；或按项目定位使用「蹭名主词 + 品类词/升华载体」。

### 合作曲增补性状（11-15）

11. **典故私人化**：神话/历史典故不点典名，第一人称当事人视角。
12. **单一隐喻贯穿**：整首歌只花一个比喻的钱，层层加码。
13. **物件叙事闭环**：开头物件→结尾物件呼应，给开放结尾实体落点。
14. **感官物+抽象品质错位**：把声音写成「诚实的」、把质感写成「软的」——用抽象品质修饰具体感官物。
15. **时间差残酷**：山中半年人间换代 / 借来的时光——时间差 = 痛感放大器。

**自查清单（写完词过一遍）**：□钩子段在副歌前 15 秒内？□双清单在场？□隐喻只花一个的钱？□物件闭环？□气声 outro？□曲名高搜索？□路径定位与词作指向一致？

## 第三步：曲名体系化

- 曲名 = 高搜索词（性状 10）+ **子系列前缀**（以统一前缀形成搜索联想 + 品牌感）。
- 系列化命名保持；新系列先定前缀。
- 重名检查：在项目全库扫描零命中；做蹭热度判定（对标已有高搜索量关键词：食材/地名/场景/流行语）。
- 曲名不受字数限制；判据是「源于生活、高于生活」——从生活现场升维到高级意象域，禁把生活事件名直接当曲名（除非本身有反讽张力）。

---

## 第四步：发行配套

> 以下为**实测经验**，不是平台承诺；按目标平台当前规则与自身数据校准。

1. **合作署名 = 进池的经验杠杆**：实测中合作署名与推荐池准入强相关（因果未分离——可能是算法奖励合作，也可能是合作者借池）。按强经验杠杆执行，不当已理解机制；合作者量级差异系小样本，仅作人选参考。
2. **同日成组发行（4-6 首/组）= 操作效率惯例**：价值 = 同日批量走发行流程 + 同批统一观察；**「同发互相带量」不被保证**——勿指望成组联动。
3. **D0/D1 不读数据，观察点 D2-D3**：D0≈0 常系平台尚未入库；判死刑时点 = D3-D4，峰值日 = D2，衰减 = D5；先把数据等出来，别拿 D0 的零当「冷启动失败」。
4. **诊断先按署名分层再比较**：solo 集体沉底可能是预期行为；仅当同层合作曲也集体沉底（≥3 首同批低于阈值）才启动归因。

## 第五步：数据反馈循环（本 skill 的活性机制）

```
每批发行 → 3 天后采集 → 归因分析
  → 哪些性状在 winners 里高频出现？→ 性状库增删（双实例门槛）
  → 爆款个案 → 立项解构 → 性状回喂
```

- 性状增删门槛：复现（下批还用）× 验证（≥2 实例）× 工程级。
- 单实例不立性状（留观察不立规）。
- 每季度性状态盘：连续两批无正反馈的性状标注「待重验」。
- **回喂前置：先按署名分层再归因**——solo 沉底不构成性状淘汰证据；性状结论只在同层内比较。

## 爆款复刻阶梯（可选）

> 复刻 = 配方复刻 + 授权内引用；「可以抄」不等于「可以侵权」。

| 级 | 操作 | 发行边界 |
|---|---|---|
| **L1 同名同词照搬** | 母本原词注入 + 新旋律；曲名同名 | ❌ 无授权 = 翻唱类发行可能要求版权证明；✅ 取得授权可发行 |
| **L2 hook/副歌整段原句 + 新主歌** | 母本 hook 原句照用 + 同赛道新意象群 | ⚠️ 灰带：非公版须创作者显式拍板并留痕；平台过审 ≠ 法律安全 |
| **L3 配方复刻 + 短语引用（≤1 句）+ 曲名蹭名** | 七维配方复刻（BPM/调式/编配/结构/意象/工艺/情绪） | ✅ 思想区无需授权；引用仍须留痕 |

**降级判据 =「流程走不通」**：平台审核拒 / 表单拦截 / QC 不过 → 降一级重创替补。
**授权边界**：非公版原句引用 = 版权决策，须创作者显式拍板留痕；每首曲目文件留痕母本/复刻级/引用位置。
**借鉴边界**：复刻前先定「阶梯 × 授权意图」；平台过审 ≠ 法律安全（思想/表达二分）。

---

## 边界

- 性状库基于特定平台的数据；其他平台不直接适用，按目标平台重新校准。
- 相关性 ≠ 因果：合作署名与流量是强相关，但因果未分离且可能与题材共线——按强经验杠杆执行，待验证。
- **反面清单**：
  - ❌ 不指望「站外火 → 站内涨」：跨引擎相关性可能接近零。
  - ❌ 不以「老歌长尾」作规划前提：存量复利弱，大盘主要靠新批供给。
  - ❌ 不依据「发行时段」选时辰：时段效应可能是批次的代理变量。

## 与其他 skill 的关系

```
hit-pattern-craft（本 skill：定位 + 性状 + 发行配套）
  ← 写词前定位
  → imagery-craft / story-craft / whitespace-craft（单维度词作技法）
  → orchestration-craft（配器维度）
  → music-creation-workflow（Prompt 工程）
  → launch-strategy（上线计划与变现）
```

**与 launch-strategy 的分工**：launch-strategy 管专辑上线计划/投放/变现（商业层）；本 skill 管**单曲的流量路径定位与性状自查**（创作层）。

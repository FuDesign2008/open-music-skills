# 画面感创作指南（imagery-craft）

> **定位**：**创作时的画面感技法指南（主）+ 写完自检（辅）**。把画面感公式融入创作过程，而非事后检查。是 `music-creation-workflow` 写歌词阶段的创作增强层，与「感官锚点及格线」「概念服务情感原则」、`whitespace-craft`（编曲留白）互补。
> **依据**：方文山亲笔书 + 学术论文 + 百首词频统计，三方互证（本 skill 已把方法论提炼为可操作清单，读者无需访问原始调研）。

---

## 一、核心心法

画面感公式：

> **(人称主语 + 具象词汇) × (比喻/比拟 + 语法重构) = 画面感**

一首歌词 = 一部电影：**人（主语）+ 物（名词）+ 人物互动（动词/形副）**。灵魂在两处：① 比喻/比拟修辞（无形→有形）；② 打破汉语语法的词性活用（陌生化）。

**本 skill 的核心理念**：画面感不是写完再查有没有，是**写的时候就主动构建**。10 维度不是检查表，是**创作清单**——写词时逐项主动考虑。

**与及格线的分工**：及格线 = 每首有无 2–3 个感官锚点防空洞；本 skill = 创作时就把画面感做到极高。

## 二、创作方法论（核心 · 三阶段）

### 阶段 1：写词前——定画面地基

动笔前先定四件事，画面感才有骨架：

1. **定核心意象**（这首的「画面主角」）
   - 问：这首歌用什么具体物象承载情感？例：摩天轮/一臂之遥、青花瓷的「瓷器」、东风破的「酒壶」
   - 核心意象 = 情感载体（借物喻情）
2. **选流派意象库**（维度⑧来源）—— 见第四节流派意象库表
3. **定 1–2 个目标修辞**（这首打算用什么手法）
   - 至少想好：1 处比喻/比拟 + 1 处词性活用（最易被忽略的签名手法）
4. **选金句载体族**（金句起手式，见第五节）——先定「全曲最强那句用什么载体承住」，再造句

### 阶段 2：写词中——用公式构建（10 维度作创作清单）

写每一段时，主动逐维度构建（**不是事后查，是写时就考虑**）：

| 维度 | 写词时主动问自己 | 实例 |
|------|---------------|------|
| ① **人称代词** | 副歌锚定你我他了吗？ | 「天青色等烟雨，而我在等你」 |
| ② **具象名词** | 这段投了画面词（JPG）吗？ vs 全抽象？ | 月光/风铃/琴弦/侧脸 |
| ③ **画面动词** | 用了让画面动（AVI）的动词吗？ | 转身/搁浅/缠绕 |
| ④ **上色形容词** | 有招牌质感词吗（不只通用「美丽/难过」）？ | **斑驳**/失焦/锈/潦草 |
| ⑤ **比喻** | 至少 1 处抽象→具象？ | 「思念像底格里斯河蔓延」 |
| ⑥ **比拟** | 至少 1 处拟人/拟物（无形→有形可触）？ | 「天青色等烟雨」「一壶漂泊」 |
| ⑦ **词性活用** ★ | 至少 1 处打破语法（签名手法）？ | 「凄美了离别」「为遇见你伏笔」 |
| ⑧ **考据细节（真实锚定）** | 投了流派器物/时代词吗？**锚定到真实可指认了吗**（地名/场景/动作）？ | 素胚/汉隶/百乐门；深化→游乐园的跳楼机/外婆灶台/玉林路 |
| ⑨ **蒙太奇** | 段落间场景切换了吗（非单一平铺）？ | 古今/场景跳跃 |
| ⑩ **留白伏笔** | 有未说尽句/伏笔吗？ | 「飘落了灿烂」 |

> **写词时就带着这 10 项**——尤其 ⑥比拟 ⑦词性活用（最强签名，最易被忽略，事后查才发现缺，不如写时就构思）。

### 阶段 3：写词后——自检（评分验证）

写完后用 10 维度评分自检（0–2 分，总分 0–20），标薄弱维度补强。**自检是辅助，不是目的**——目的是阶段 2 就把画面感做足。

## 三、10 维度自检评分（写完后用）

每维度 0–2 分（0 无 / 1 有但弱 / 2 突出），总分 0–20：

- **0–7 弱**（画面感不足）/ **8–13 中**（及格但不突出）/ **14–20 强**

标 ≤1 分的薄弱维度，逐条给提升建议（仅建议，不自动改写）。

```

IMAGERY 自检报告
文件：<歌词文件>
流派：<中国风/都市/电子/...>
总分：X/20（弱/中/强）
═══════════════════════════════════════════
①人称 X/2  ②具象 X/2  ③动词 X/2  ④质感 X/2
⑤比喻 X/2  ⑥比拟 X/2  ⑦活用 X/2  ⑧考据 X/2
⑨蒙太奇 X/2  ⑩留白 X/2
薄弱维度（≤1）：……
亮点：……
提升建议：……（不自动改写）
判定：建议性正向技法自检，有意的创作选择有效。
```

## 四、流派意象库（维度⑧按流派匹配）

公式源于中国风，但**技法通用，意象来源随流派**：

| 流派 | 意象库示例 |
|------|----------|
| 中国风/古风 | 素胚/宣纸/汉隶/仕女图/泼墨/炊烟/洛阳 |
| 都市/R&B | 便利店/地铁/手机/外卖/出租屋/末班/屏幕 |
| 情感电子 | 霓虹/信号/航班/数据/电流/屏幕/云端 |
| 复古/怀旧 | 磁带/舞厅/卡带/收音机/胶片/八零年代 |
| 民谣 | 木吉他/山岗/麦田/老屋/炊烟/河流 |

> 写词前先判流派（看项目定位 / Style），按对应意象库构建维度⑧。

### 真实锚定深化（⑧的强化 · 修正「泛化抽象具象」空洞）

**问题**：意象库（素胚/便利店/航班）是**泛化类概念**——哪里的便利店？谁的航班？听众无法链接真实世界 → 空洞。

**真实锚定**（grounding）：把泛化器物推到**真实可指认**（地名/地标/具体场景/真实动作）：
- 泛化「跳楼机」→ 真实「游乐园最晚一班次后的跳楼机」（听众去过就代入）
- 泛化「余烬」→ 真实「外婆灶台没拨开的炭」
- 泛化「便利店」→ 真实「凌晨三点的便利店」
- 泛化「一条街」→ 真实「玉林路」「安和桥」（民谣地名传统）

**价值**：① 细节更丰富可信（真实>虚构）② 听众链接真实世界（共鸣/代入）③ 不空洞。

**7 锚定法**：真实地名地标 / 具体场景物件 / 真实动作细节 / 时代时间 / 真实感官 / 地名深化为情感 / **真实但可共享**（通用真实地名如外滩/西湖，非过度个人化）。

**边界**：地名/地标/场景 ✅（无版权，民谣/流行传统）；艺人名/作品名 ❌（平台过滤风险）；**品牌名谨慎**（优先通用地名与公共场景，避免商业品牌直接入词）。

### 宋韵线增补：物库 · 听写 · 使用痕迹

> 「用宋的方式看当代生活」（审美机制，非古风元素；题材永远是今天）。三条供**简素／日常／器物向**创作按需取用，不构成新门槛。

- **宋式物库**（意象库扩容）：茶盏／线香／瓷／灯／伞／信纸——在当代语境里使用（围炉煮茶／新中式已被年轻人日常化，不写成古装场景）。
- **听写**（声景意象）：雨打窗／水开／风铃／消息提示音——情绪交给**声音事件**承载（不写「我想你」，写「水开了两次」）。
- **使用痕迹**（⑧考据细节维升级）：物不只要真实可指认，还要**被生活用过**——磨亮的刀柄＞崭新的刀；物已带情节，不必再解释。

### 单色反向纪律（减维运用）

> 阶段 2 的 10 维度默认**逐维富集**；本条是有意的**减维模式**——两个方向都在，判据是「有意与否」（同 §八）。

- **收敛纪律**：一首歌的主意象收敛 **1–2 族**（如全曲只在「器物＋天气」两族内轮换）；**>3 族＝意象杂烩**（单色破——多≠好：一个承重意象＞三个装饰意象）。
- **同族轮换不算破**：泡沫／花火／星同属光学域——轮换得起，跨族堆砌才破。
- **减维不是简陋**：少而精＝表现力压进极少变量（是**名词的密度**，不是形容词的密度）——砍完须形态自足。

## 五、金句载体选型（学习自国民金曲）

> **本节只放起手式与速查**；每族的生成步骤/代表例/自检需要更深的词法档案时，按需自建扩展阅读。

### 5.1 核心工作法：选族先于造句

**金句 = 情感内核 × 一个可指认的载体**。同一情感内核换载体就是另一首歌——同写「不甘」：走矛盾并置得张力、走断言锤得宣言、走一物到底得寄托。

工作顺序：**定情感内核 → 从下表选一族（=选定载体类型）→ 再套该族生成步骤造句**。反过来（先写出漂亮句子、再回头找载体）常得到「句好但空」——没有承重结构的句子留不住。

### 5.2 十一族速查（族 / 载体 / 机制 / 代表模式）

| 族 | 载体是什么 | 一句话机制 | 代表模式 |
|---|---|---|---|
| 1 矛盾并置 | 一对互斥项 | 张力代替形容词，「不可解」即情感真相 | 互相折磨到白头 |
| 2 复沓回环 | 一个重复单元（字/词/句式） | 重复即记忆；听众记住的是语法结构 | 从前从前 |
| 3 断言锤 | 一句短判断/否定态度 | 句越短锤越重；断言可被听众抄作签名 | 爱本是泡沫 |
| 4 概念系统 | 一套术语体系 + 自造名词 | 单一隐喻系统贯穿 = 成本最低的升维 | 戏剧术语贯穿全曲 |
| 5 一物到底 | 一个物/景/动作/喻体 | 具象物 = 听众可指认的把手 | 《年轮》《戒烟》 |
| 6 量化刻度 | 一个数词/时间刻度 | 把不可计量之物切成可指认的份数 | 一半 |
| 7 问答召唤 | 一次对话动作（问/祈使/呼告） | 把听众变成「被问/被喊」的人 | 回家吧 |
| 8 反转揭底 | 一次信息翻转（末段改写） | 只改一个成分，落差最大、成本最低 | 尾句变体 |
| 9 时空坐标 | 一组时间/假设坐标 | 虚拟语气 = 情绪容器，可写未发生的事 | 十年之前／十年之后 |
| 10 锚定升维 | 一个专有名词/超大尺度 | 泛化情绪获得坐标与搜索性 | 光年之外 |
| 11 语言破格 🆕（候选族） | 语言形式层的**一次破格**（词义/语法/语音/语体/语用） | 载体不是「物」而是写法——「不对劲」本身制造停顿与记忆 | 有点甜（降调味觉） |

**分布提示**：**复沓、断言锤、矛盾并置是最大三族**——「重复一个单元」「下一句断言」「塞一对矛盾」是三大低成本技术；稀缺族 = 时空坐标、锚定升维、概念系统、反转揭底——**用得少 = 撞车少，是差异化机会区**。

### 5.2.1 每族生成步骤（选族后照此造句）

> 每族给出一句话生成步骤 + 自检问句；族 5 另有完整六步法（见 5.4）。

| 族 | 生成步骤（一句话） | 自检 |
|---|---|---|
| 1 矛盾并置 | 把情感的两个不可调和面各写成半句，**不加解释地并置** | 两句是否互相否定？ |
| 2 复沓回环 | 选一个单元（字/词/短句），**在关键位置原样重复 ≥2 次** | 去掉重复后是否失去节奏记忆？ |
| 3 断言锤 | 用一个**极短判断句**（≤10 字）收束一段，态度明确、不加修饰 | 这句能被听众抄成签名吗？ |
| 4 概念系统 | 选一套术语（戏剧/医学/棋局…），**全曲统一用它作隐喻** | 换成别的术语系统会崩吗？ |
| 5 一物到底 | 见 5.4 六步法 | 把物换掉后全曲是否崩塌？ |
| 6 量化刻度 | 把抽象情感**切成可计数的份数**（一半/三次/第几年） | 数字是否可指认、不俗套？ |
| 7 问答召唤 | 用一次**问句/祈使/呼告**把听众拉进对话位 | 听众是否被迫成为被问的人？ |
| 8 反转揭底 | 在全曲末段**只改一个成分**（时间/人称/对象），制造落差 | 落差是否只用一处改动完成？ |
| 9 时空坐标 | 用**一对时间/假设坐标**（十年之前/如果那天）框住情绪 | 坐标是否虚拟却可信？ |
| 10 锚定升维 | 用一个**专有名词或超大尺度**给泛化情绪安坐标 | 是否获得搜索性与画面？ |
| 11 语言破格（候选） | 只破一层（词义/语法/语音/语体/语用），放曲名或副歌首句 | 破格是否只发生一次且可复现？ |
> ⚠️ **族 11 标注为「候选族」，暂勿当正式族使用**：样本未足，待更多验证。**8 子机制速查**：① **词义翻转** ✅ 可用（中性/降调词配笃定句式——「有点甜」式）｜② 语法破格（故意错一格：形容词带宾语／否定假设本身）｜③ 语音专名（造超长怪名当 hook）｜④ 感官移植（听声见色／剥夺一种感官）｜⑤ 语气不确定（「好像/也许」+ 极确定宾语）｜⑥ 陈词拒用（点破其陈，见 `voice-checker`）｜⑦ 俗语翻新（俗语回文／顶针压缩）｜⑧ 语体落差（4 字庄语 + 4 字白话）——②–⑧ 均候选。用法三步：只破一层 → 放曲名或副歌首句 → 全曲复现 ≥2 次（选它时辅以其他族的稳载体）。

### 5.3 双写路径（最该走的路径）

**公式：具象日常锚点 × 升维载体**

- **锚点**：每段至少 1 个可指认的具象物（稻田/蜻蜓/纸飞机、小方桌/一荤一素）——即本 skill ②具象名词维度的落点，也是感官锚点的来源
- **升维**：每段至少 1 句高级承载（童话域「家是唯一的城堡」/尺度域/术语域）——即「载体升维」原则的落点
- **公共地理域归属**：真实地名承载归为「具象锚点」侧——地名负责代入面，**不构升维**；升华仍靠升维载体承担。故写「玉林路」是补锚点、不是走了升维路径——两笔账要分开记
- **反向教训**：纯升维型（无生活白描层）具象度会掉到 3——现代创作更可取的是双写，不是满篇星空魔法
- **与载体升维原则的接口**：**升华 ≠ 意象华丽**。判据的正确操作定义 = **情感有没有被一个载体承住**——载体可以是物、是术语系统、是一个主题词（「慢慢」）、甚至是一次场景升级（把出租屋的遗憾抬到婚礼）。禁的是「没有载体的事件平铺」，不是「没有星空魔法」

### 5.4 一物到底六步法（族 5 摘要——最易上手）

1. **选物**：与情感**同构**（年轮 = 层层累积；戒烟 = 戒断反应；风 = 不可握留）
2. 找出该物的**动作/生长/操作逻辑**，把关系阶段映射上去（发芽→茂盛→被砍）
3. **主歌全用该物的物候/操作细节，不换物**；副歌把物与人连通
4. **动词化/人位让渡**：让物做动作、人做受事（「塞北残阳是她的红妆」比「她穿红妆」高一档）
5. **一物到底纪律**：全曲不引入第二个**主喻体**（同族轮换可：泡沫/花火/星同属光学意象域；跑题换物不可）
6. **自检**：把物换成一个词，全曲是否崩塌？**不崩塌 = 物没承重**

## 六、创作工作流（融入创作，非事后）

```
写词前（阶段1）：定核心意象 + 选流派意象库 + 定 1-2 目标修辞 + 选金句载体族（第五节）
   ↓
写词中（阶段2）：10 维度作创作清单，逐段主动构建（重点 ⑥比拟 ⑦词性活用）
   ↓
写词后（阶段3）：10 维度评分自检（0-20），标薄弱补强
   ↓
（进入 music-creation-workflow 的整体审查 / pre-generation-check）
```

**关键**：阶段 2 是核心——写词时就带着 10 维度构建，而非写完才发现「没比拟、没词性活用」再补。

## 八、铁律

1. **创作时主动构建为主，自检为辅**——本 skill 的价值在阶段 2（写时融入），不是阶段 3（事后查）
2. **仅建议，不自动改写**（自检阶段）——评分+方向，作者决定改什么（同 `voice-checker`）
3. **流派敏感**：维度⑧按流派意象库，不强求古典
4. **有意的选择有效**：极简风有意少意象、说唱有意密集——问「这是有意的吗？」
5. **画面感服务情感**：修辞为情感载体，不为修辞而修辞、不破坏风格
6. **先过及格线再谈优秀**：若歌词连感官锚点都没有，先补锚点

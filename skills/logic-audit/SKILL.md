# 专辑逻辑一致性审查（logic-audit）

> **定位**：曲目文件修改后的逻辑质量保障。发现 → 分类 → 自动修复（机械问题）/ 提出决策（叙事问题）。
> **适用范围**：单曲目审查（修改后检查该曲目 + 受影响的相关曲目）；整张专辑审查（全部曲目文件 + 专辑索引/说明）。

## 触发词

- **逻辑检查 / 检查有没有逻辑问题 / 逻辑问题**：运行全部审查维度
- **专辑检查**：含硬约束 + 逻辑一致性的全量审查
- **一致性审查**：重点查索引同步（专辑索引/说明 vs 实际曲目文件）

---

## 审查维度（四族展开为 D1–D7）

- **时间/情绪/叙事族**：D1 时间场景、D2 情绪-角色、D3 跨曲目叙事
- **自检表族**：D4 自检表准确性
- **锚点与索引族**：D5 感官锚点、D6 元数据与索引同步
- **歌词自洽族**：D7 歌词内部逻辑

### D1：时间场景一致性

**触发条件**：曲目的时间场景被修改过（如凌晨→上午、深夜→月末周五）

| 检查项 | 方法 |
|--------|------|
| 歌词中是否残留旧时间场景引用 | grep 凌晨/天亮/深夜/黎明/通宵/窗外/moon/dawn/midnight 等 |
| Outro 的时间逻辑是否与新场景一致 | 新场景为「上午十点」但 Outro 写「窗外亮了」→ 逻辑断裂 |
| 核心意象描述是否与歌词时间一致 | 比对「定格意象」字段与歌词实际时间 |

**常见失败模式**：
- Verse 1 改成了上午，Outro 却还在描述天亮
- 时间改了但「核心意象」段落仍描述旧场景

### D2：情绪-角色匹配

**触发条件**：曲目的情绪标签被修订过

| 检查项 | 方法 |
|--------|------|
| 歌词内容是否支撑新的情绪标签 | 标签「赞叹/甜蜜依赖」但歌词全是恐惧描写 → 错配 |
| 角色第一人称是否与歌词一致 | 标签「上午十点」但歌词行为暗示通宵 |
| 声线描述是否匹配新情绪 | 平台声线指令更新后，同步所有引用处；核对资产实际音色与歌词情绪的一致性 |

**常见失败模式**：
- 情绪改了但自检表中仍引用旧 Prompt 的情绪描述词
- 情绪/声线/曲风对照表中的描述仍为旧版

### D3：跨曲目叙事连续性

**触发条件**：存在明确关联的曲目（如前曲→后曲同一人叙事）

| 检查项 | 方法 |
|--------|------|
| 角色细节是否一致 | 对比年龄、性别、经验年限、核心场景 |
| 情绪弧线是否连贯 | 前曲结尾状态 → 后曲开头状态是否合理衔接 |
| 意象回调是否准确 | 「跟那天一样」的「那天」在前曲中是否存在且描述一致 |
| 软指南中的跨曲引用是否正确 | 「呼应前曲结尾画面」→ 前曲结尾实际是什么画面 |

**常见失败模式**：
- 前曲结尾在地铁，后曲开头在电脑前 → 时间跳过合理但软指南声称「呼应结尾画面」就不对
- 教义编号/内容在专辑索引和曲目文件中不一致

### D4：自检表准确性

| 检查项 | 方法 |
|--------|------|
| Prompt 字符数（标签式平台） | 脚本实测 vs 自检表声明（修改后最易漂移） |
| 词量/时长锚句/音色匹配（自然语言式平台） | 自检表词量声明 vs 实际字数；时长锚句是否在位；音色匹配记录 vs Style 声线句与资产实际音色 |
| 情绪描述引文 | 自检表的引文是否存在于实际 Prompt 中 |
| 声线描述引文 | 同上 |
| BPM / 调式 | 自检表值 == 实际 Prompt 中的值 |
| 结构要求引文 | 引文是否精确匹配（注意遗漏的形容词） |

**常见失败模式**：
- 字符数全盘过时；词量与音色记录漂移
- 自检表引用的词在 Prompt 中不存在（「tense」→ 实际是「warm」）
- 引文截断开头形容词

### D5：感官锚点完整性

| 检查项 | 方法 |
|--------|------|
| 是否存在重复行 | 同一锚点文字出现两次 |
| 锚点文字是否在歌词中实际存在 | 逐条在歌词中搜索 |
| 出现位置是否准确 | 表称「Verse 1 / Outro」但仅 Verse 1 有 |
| 唯一锚点数量 | 去重后 ≥ 2，目标 2-3 |

**常见失败模式**：
- 两行锚点完全重复（复制粘贴遗留）
- 锚点位置声称在 Verse 1 但 Verse 1 完全没有该文字
- 去重后只剩 2 个，自检表却说有 3 个

### D6：元数据与索引同步

| 检查项 | 方法 |
|--------|------|
| 专辑索引的情绪/角色/意象 vs 实际曲目文件 | 逐行比对 |
| 专辑说明的氛围关键词 vs 实际曲目文件情绪 | 逐行比对 |
| 专辑说明的调式速度总表 vs 曲目文件实际 BPM/Key | 逐行比对 |
| 教义/设定文本完整性 | metadata 表 vs 文件 header vs 专辑索引 |
| 专辑背景故事是否含已删除的场景 | 背景故事提到「凌晨三点」但歌词已取消 |

### D7：歌词内部逻辑自洽

| 检查项 | 方法 |
|--------|------|
| 同一首歌内是否有自相矛盾的句子 | 「看都没看」vs「每一行我都读得懂」 |
| 隐喻体系是否自洽 | Chorus 声称「五重意象」但只列了 3 个 |
| 角色 POV 是否一致 | 第一人称叙述中是否突然跳视角 |

## 执行方法

### 标准流程

```
1. 并行派出 3-4 个 explore agent（每 agent 覆盖 2-3 个维度）→ 后台运行
2. 同时做直接检查（bash/grep）— 字符数、时间引用、括号规范
3. 等 agent 返回 → 汇总分类：
   - 硬伤（可自动修复）：字符数、去重、引文对齐
   - 软伤（需用户决策）：叙事张力、隐喻自洽、背景故事更新
4. 自动修复硬伤 → 提出软伤选项等用户决策
```

### Agent 分工建议

| Agent | 覆盖维度 | 提示要点 |
|-------|---------|---------|
| Agent A | D4（自检表） | 逐文件比对自检表引文 vs 实际 Prompt 内容 |
| Agent B | D3+D1+D2（叙事连续性/时间/情绪） | 重点查跨曲目角色一致性 + Outro 时间矛盾 |
| Agent C | D5+D6（锚点+索引） | 逐文件比对感官锚点准确性 + 索引同步 |
| Agent D（可选） | D7（歌词自洽） | 逐首读歌词找内部矛盾（适合修改幅度大时） |

### 直接检查（不依赖 Agent）

```bash
# 时间场景残留
grep -n "凌晨\|天亮\|深夜\|黎明\|通宵\|窗外" <曲目文件>

# Prompt 字符数（精确值）
python3 - <曲目文件> <<'PY'
import re, sys
fence = chr(96) * 3
s = open(sys.argv[1]).read()
m = re.search(re.escape(fence) + r'\n(.+?)\n' + re.escape(fence), s, re.S)
print(len(m.group(1)) if m else "no prompt block")
PY

# 自检表字符数声明 vs 实际
grep "约 [0-9]* 字符" <曲目文件>

# 括号规范（按目标平台规则；自然语言式平台无此检查）
grep -c '(' <曲目文件>
```

## 修复策略

### 自动修复（直接执行，无需询问）

| 问题类型 | 修复方式 |
|----------|---------|
| Prompt 字符数过时（标签式平台） | 更新自检表为实测值 |
| 词量声明过时（自然语言式平台） | 更新自检表词量声明为实测值 |
| 感官锚点重复行 | 删除重复行 |
| 引文与 Prompt 不匹配 | 替换为 Prompt 中的实际文字 |
| 教义文本截断 | 补齐完整教义文本 |
| 索引表与曲目文件不同步 | 同步至曲目文件实际内容 |

### 需用户决策（提出选项，等待确认）

| 问题类型 | 原因 |
|----------|------|
| 歌词有意的内在张力 | 可能是角色弧线，不是 bug |
| 情绪光谱分类重新归类 | 涉及专辑整体设计 |
| 专辑背景故事中的文学夸张是否更新 | 歌词改了但背景故事是叙事性描述，不一定需要同步 |
| 感官锚点数量不足（<2） | 需要创作补充，不是机械修复 |

## 与 pre-generation-check 的关系

| 维度 | pre-generation-check | logic-audit |
|------|---------------------|-------------|
| 定位 | 生成前最后一道门 | 修改后的质量保障 |
| 检查范围 | 硬约束（平台规则/长度/段标/发音等） | 硬约束 + 叙事逻辑 + 索引一致性 |
| 修改能力 | 只报告不修改 | 自动修复机械问题 |
| 运行时机 | 准备生成前 | 每次修改曲目后 |

**推荐工作流**：修改曲目 → logic-audit → 修复 → pre-generation-check → 生成

## 快速参考：修改后必查清单

每次修改曲目文件后，至少确认：

- [ ] 歌词中无旧时间场景残留
- [ ] 自检表字符数/词量与实际一致
- [ ] 自检表引文与实际 Prompt 匹配
- [ ] 感官锚点无重复行，锚点文字在歌词中存在
- [ ] 专辑索引对应曲目行是否已同步
- [ ] 专辑说明关键词表/总表是否已同步
- [ ] 如有跨曲目关联，叙事连续性未断裂

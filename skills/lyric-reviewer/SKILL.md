# 中文歌词质量审查器（lyric-reviewer）

> **定位**：写词与生成之间的质量控制门。发现问题、提出修复建议；仅结构标记缺失等明确项可自动修。
> **适用范围**：项目中的歌词文件；中文歌词为主；单曲或整张专辑均可。

## 触发词

- **审查歌词 / 检查歌词 / 歌词审查 / 歌词质量**：运行 16 点审查清单
- **lyric review**：英文触发
- **金句承重 / 峰值位置 / 洞见检查 / 单色检查**：专项审查
- **情理钻石 / 选题锚点 / 浓度检验 / 无病呻吟 / 情感不够浓烈**：重点检查对应项

---

## 16 点审查清单

### 1. 韵脚检查

| 项目 | 标准 |
|------|------|
| 检查 | 是否有韵脚体系（不要求每行押韵，但整体应有韵脚意识） |
| 检查 | 换韵是否合理（Verse 和 Chorus 建议换韵增加段落对比） |
| 检查 | 是否存在为凑韵而生硬使用的词或不自然表达 |
| 检查 | 是否存在连续 ≥6 行押同一韵脚不换韵（韵脚疲劳） |
| 严重度 | 生硬凑韵 = Warning；韵脚疲劳 = Info |

### 2. 音节/节奏检查

| 项目 | 标准 |
|------|------|
| 检查 | 每行字数是否在可唱范围内（中文歌词建议 5-12 字/行） |
| 检查 | 同一段落内行与行之间字数是否基本均衡（±3 字以内） |
| 检查 | Verse 和 Chorus 是否有节奏对比（如 Verse 短行、Chorus 长行） |
| 严重度 | 行长度严重不均衡 = Warning；轻微差异 = Info |

### 3. 结构检查

| 项目 | 标准 |
|------|------|
| 检查 | 是否含段落结构标记（`[Verse]` `[Chorus]` `[Bridge]` `[Outro]` 等） |
| 检查 | Verse 与 Chorus 是否有内容对比度（Verse 叙事/铺陈，Chorus 点题/升华） |
| 检查 | V2 是否有递进（不是 V1 的简单重复） |
| 检查 | 段落数量是否合理（建议 2 Verse + 一段 hook 高潮 + Bridge，避免 4-5 段 Verse） |
| 严重度 | 缺少结构标记 = Critical；V2 无递进 = Warning |

### 4. 视角一致性与分布

| 项目 | 标准 |
|------|------|
| 检查 | 视角是否一致（单曲内：若用第二/第三人称或对话体，是否一致且有题材理由，无视角突变） |
| 检查 | 是否存在视角突变（如突然从「我」切换到「你」且无过渡） |
| 检查 | **专辑层视角分布**（整张审查时）：视角 ≥3 种且第一人称自述 ≤60%；判「谁在讲」的叙事结构，不判「我」字频率——冰山手法字面低我但结构仍可单一 |
| 严重度 | 视角不一致 = Warning；专辑层光谱超标 = Warning |

### 5. 段落长度检查

| 项目 | 标准 |
|------|------|
| 检查 | Verse 行数是否合理（建议 4-8 行，不超过 12 行） |
| 检查 | Chorus 行数是否合理（建议 4-8 行） |
| 检查 | Bridge 行数是否合理（建议 2-6 行） |
| 严重度 | 严重超长 = Warning |

### 6. 情绪可及性

| 项目 | 标准 |
|------|------|
| 检查 | 歌词中是否包含 2-3 个具体感官碎片或事件锚点 |
| 检查 | 剥离所有外部知识后，陌生听众仅凭歌词能否说出「这首歌的情绪来自什么」 |
| 严重度 | 全抽象无锚点 = Warning |

### 7. 艺人名检查

| 项目 | 标准 |
|------|------|
| 检查 | 歌词中是否包含已知艺人/乐队名（歌词段 Info 级提示，创作者自判） |
| 检查 | Prompt 中是否包含已知艺人/乐队名（调用时同时检查 Prompt 段落） |
| 参考 | 自建「艺人/乐队名清单」；平台过滤规则以目标平台为准 |
| 严重度 | **Prompt 段**发现禁用名称 = **Critical**（必须修改）；**歌词段** = Info（仅提示，不阻断） |

### 8. Prompt 长度 / 词量门

| 项目 | 标准 |
|------|------|
| 检查（标签式平台） | Prompt 段落字符数是否 ≤ 目标平台上限（示例：1000 字符，含空格和换行）；是否用工具精确计数 |
| 检查（自然语言式平台） | 词量是否达到平台时长模型的可靠区间（示例：慢/中板 3 分钟+ 约 580+ 字；快板/短行词例外） |
| 严重度 | 标签式平台超上限 = **Critical**（可能导致生成异常）；词量不足 = **Warning**（时长偏短风险，交创作者权衡） |

### 9. 结构层审查

> **为什么有这一条**：其余各项多审**字面层**（韵脚/节奏/段标/AI 味），但叙事结构层的错配会被字面全绿掩盖。判结构不只判字面：感知单元是叙事结构。

| 子项 | 标准 | 严重度 |
|------|------|--------|
| **刻度匹配** | 题材-刻度对了吗（愁思→冰山白描/哲思→画卷客观/豪放狂想→意象升华外扬/枭雄之豪→内藏双层） | 错配即返工（Warning） |
| **降格红线** | 企划/创作说明含「剥掉 XX 背景=每个当代人」句式？**升华刻度题材被降格为写实白描 = Critical（阻断）** | Critical |
| **表里双层** | 内藏型题材（枭雄/深藏之豪）：表面与底里都在吗（表层诗意+底下江山，禁直喊王图霸业，谜底尾句点破） | Warning |
| **升华度** | 升华刻度题材：夸张尺度意象在场吗（神话数字/天地尺度/不可能动作）——只有写实物象=降格。非诗词题材：载体升维在吗——日常情感内核不变而载体升到高级意象域？事件名/场景平铺且无升华=「场景白描式朴实」 | Warning（交创作者判） |

### 10. 金句承重检查

> **为什么有这一条**：前 9 点全绿，仍可能「句句通顺、无一句立得住」——全曲最强的那句若没有载体承住，整首歌就缺一个能被记住、被引用的落点。

| 项目 | 标准 |
|------|------|
| 检查 | 全曲最强句是否有**一个可指认的载体**承住？载体任选其一：一个物/景、一套术语系统、一个概念词、一个主题词、一次场景升级 |
| 承重测试 | 把金句的载体抽掉，句意是否塌？**塌 = 有承重；不塌 = 只是顺口的好句子** |
| 可指认性 | 载体能否被听众一句话指出来（「那首讲戒烟的歌」）？说不出 = 载体不在场 |
| 严重度 | **Warning（非阻断）**——朴素直白 ≠ 无升华：情绪宣言式朴实可（曲名本身即态度），禁的是**场景白描式平铺** |

### 11. 峰值位置检查

> **为什么有这一条**：默认「把最强句塞进副歌」是未经检查的成见——它会逼着把桥段/尾声里本可独有的一句硬挪进副歌，反而稀释。

| 项目 | 标准 |
|------|------|
| 检查 | 峰值位置是否**有意识设计**——开局前已在「递进式／首现式」二选一？桥段或尾声若有独有素材，是否允许它留在原处？ |
| 问题形态 | **无意识平铺才是问题**——不知全曲最强句在哪、各段强度平均、靠惯性把重句全堆副歌；或走首现式却在后段继续加码（头重脚轻）。刻意无峰/平坦属有意设计，不算问题 |
| 严重度 | **Warning（非阻断）** |

### 12. 洞见检查

> **为什么有这一条**：既有检查全绿，仍可能「有画面、有承重、有峰值，却没有一句让人带走新认识」——全曲只有感觉、没有发现。

| 项目 | 标准 |
|------|------|
| **抽掉测试** | 「抽掉这首歌，听众会失去什么认识？」——答案只能写成「一种感觉/情绪」＝只有感觉（浅）；能写成**一句非歌词的发现句**＝进发现层 |
| **转述测试** | 用一句非歌词的话转述全曲发现——能转述且**不是安慰、不是祝福、不是口号**＝有洞见；转述不出＝不是深，是没说清 |
| 检查对象 | 陈述式：全曲最强句/落点句；叙事承载式：全曲思考承载（可为段级——「走过这段叙事，听众浮出什么认识？」） |
| 严重度 | **Warning（非阻断）**——共鸣层本身不构成缺陷；企划要求洞见/深度时为重点检查项，其余曲目仅作观察提示 |

### 13. 单色检查

> **为什么有这一条**：前 12 点判「句子立不立得住」，但不判「意象**数量**收不收敛」——全曲堆 4 族以上意象会互相稀释，一个承重意象被三个装饰意象冲散。

| 项目 | 标准 |
|------|------|
| 检查 | 数全曲主意象域几族：≤2 族＝绿；**>3 族＝意象杂烩警示**。同一意象域内的轮换不算破（泡沫/花火/星同属光学域） |
| 严重度 | **Warning（非阻断）**——有意密集（叙事/说唱方向）属设计选择：先问「这是有意的吗」 |

### 14. 情理钻石位检查

> **为什么有这一条**：前 13 点保证「句子立得住、意象收得拢」，但整首仍可能「太日常、单薄」——通篇白描顺畅、没有一处让人心里一亮、想复述、能带走的闪光。

| 项目 | 标准 |
|------|------|
| **数量与分布** | ≥2 处（情感型或哲理型皆可）；**跨段落分布**——不得聚在尾段/只靠末段一句撑（建议 V 系 ≥1 ＋ C/FC/Bridge 系 ≥1）。1 处＝不足（按 Critical 报告），0 处＝Critical |
| **闪光测试** | 逐处问：抽掉这一句，所在段落会不会暗下去？听众会不会想复述它？——过场句/铺垫句/纯白描句不算数 |
| **剂量五律** | 显影点 1-2 处·抽象兑现·叙事为本·副歌分工·落点——**钻石是闪光不是照明**：禁喊口号/禁说教/禁「副歌讲道理」；代价在场（不以安慰句收尾）；删掉本曲情感事件后仍像通用格言的＝概念先行→回炉 |
| **嵌合** | 生在本题材的具体物件/动作肌理里（与第 9 点载体升维协同）；不是天外飞来的格言 |
| 严重度 | **Critical**——缺位或全聚尾段＝不通过，修复后复检方可进入生成；剂量越位（说教/口号化）＝Warning 强提醒；器乐纯音乐不适用 |

### 15. 选题锚点检查

> **为什么有这一条**：前 14 点保证「歌立得住」，但若选题停在「物件小品＋对象消隐＋低唤醒温柔」，听众代入的是作者的观察而非自己的故事——「勾不动心绪」。

| 项目 | 标准 |
|------|------|
| 检查对象 | 全曲选题层——锚定「听众经历过的关系/人生时刻」（暗恋/告别/想念/毕业/家人老去/重逢…）还是「物件/场景本身」？物件是否退为道具，还是被写成了主角？ |
| 三测试 | ① **关系槽位**：听众能把自己/某个人填进去吗？（对象消隐、通篇作者独白＝⚠️）② **唤醒度**：情绪词根是否高唤醒（心动/痛/憾/燃/不甘/决绝），非低唤醒温柔/自在 ③ **可截句性**：有 1-2 句可截图当文案（与第 14 点协同） |
| 严重度 | **Warning**——器乐纯音乐不适用 |

### 16. 浓度检验

> **为什么有这一条**：此前各点判「句立不立得住/有没有钻石/锚点对不对」，但不判「全曲情感强度与承诺是否匹配」。歌名承诺「崩溃」却交付「忍住」＝承诺与实现不匹配。

| 项目 | 标准 |
|------|------|
| 检查对象 | 全曲情感浓度——歌名/题材承诺的浓度**形态**（烈/静/暖/洞察）与词实现的匹配度；「无病呻吟」＝承诺与实现不匹配 |
| 四问闸门 | ① **代价问**：全曲最大的词是否被 ≥1 处具体、未偿的损失支付（未支付大词＝违规）② **未决问**：还在路上还是已完成（完成态＝张力归零）③ **对象问**：「你」是否听众可填槽位（专名/纯道具＝⚠️）④ **贬值问**：大词密度（1 处由 2-3 处具体垫底 vs 每句一个大词）＋抽词/替换两测试 |
| 形态判据 | 定形态后对机制：**烈型**＝引爆点＋四段曲线（引信→装药→引爆→余震）；**静型**＝克制/沉默收尾压强最高；**暖型**＝被看见（给予者的克制观察）；**洞察型**＝关系真相翻译完成度 |
| 五军规快查 | 压制型情绪每段 ≥1 **泄漏动作**（情绪越过意志边界的溢出点）｜禁裸情绪命名（我好+形容词）｜每段 ≥2 身体锚点｜副歌起句禁许诺句式｜回望段末回拉现在时 |
| 严重度 | **Warning 起步**（阈值未校准——先方向后数值；不追溯已发行）——命中 ≥2 项不匹配＝建议回炉；器乐纯音乐不适用 |

> **范围说明**：本版保留 16 点框架。源版另有第 17 点「开口设计检查」（V1 首句钩力／副歌首句可截句／前 30-35 秒记忆点），其依据涉及未公开的发行数据，本版不纳入；需要时可按公开方法自建为扩展检查点。

## 自动修复

以下问题可自动修复，无需用户确认：

| 问题 | 自动修复方式 |
|------|-------------|
| 段落标记缺失 | 根据内容推断并添加 `[Verse]` `[Chorus]` 等标记 |
| Explicit 标记缺失 | 如歌词无敏感词，自动添加 `Explicit: No` |

以下问题**不自动修复**（需要人类判断）：押韵、节奏/字数、情绪锚点、视角不一致、段落递进、结构层/金句/洞见/钻石/锚点/浓度。

## 工作流

### 单曲目审查

1. Read 目标歌词文件
2. 判断是否为器乐纯音乐（是 → 跳过）
3. 定位歌词段落和 Prompt 段落
4. 逐点运行 16 点审查清单
5. 应用自动修复（如有）
6. 生成审查报告

### 整张专辑审查

1. 收集专辑目录下全部歌词文件
2. 逐首审查（跳过器乐）
3. 汇总专辑级别质量报告

## 严重度定义

| 级别 | 定义 | 处理 |
|------|------|------|
| **Critical** | 会导致生成失败或分发被拒；或创作质量门不过（情理钻石缺位/全聚尾段） | **必须修复后才能生成** |
| **Warning** | 影响歌曲质量 | 建议修复，可在修复前生成 |
| **Info** | 可优化项 | 不影响生成，有时间可改进 |

## 与其他 skill 的关系

```
music-creation-workflow（写 Style + 写歌词）
  → voice-checker（检测 AI 味，仅建议）
  → lyric-reviewer ← 你在这里（技艺审查）
  → explicit-checker（扫描显式内容）
  → pre-generation-check（最终关卡）
  → 生成
```

lyric-reviewer 和 voice-checker 互补：
- **lyric-reviewer**：检查技艺问题（结构、押韵、长度、视角、格式）
- **voice-checker**：检查真实性问题（AI 味、陈词、空洞）

## 审查原则

1. **输出是审查报告，不是修改后的歌词**：发现问题并建议修复方向；让作者或 `music-creation-workflow` 执行改写
2. **长度项按平台分叉**：标签式平台的 Prompt 字符数必须精确计数；自然语言式平台查词量门（示例 580+ 字）

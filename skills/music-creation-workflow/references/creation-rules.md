# 创作规则手册（music-creation-workflow references）

> 本文件展开 SKILL.md「核心创作规则速查」的细则。规则以**规则本身的表述**呈现，不依赖内部编号；平台专属项以「目标平台配置」为准。

## 1. 原创性与长度

- **原创性声明**：标签式平台的 Prompt 开头须含 `original composition` / `original song` 类标记；自然语言式平台按目标平台规范声明原创。
- **长度上限**：标签式平台 Style 字段 ≤ 目标平台上限（示例 1000 字符，含空格换行），写完用脚本精确计数；自然语言式平台 Style 为短指令（常见 100-207 字符），按平台习惯压缩。超限时按优先级精简非骨架句，声线/结构/制作句逐字保留（不得砍骨架换配器）。
- **不引用具体作品/艺人**：用抽象情绪/氛围描述替代；平台可能有艺人名过滤。

## 2. 情绪定调

- 每首有明确情绪主调，避免套用流行模板。
- 情绪由「乐器音色 + 演奏方式 + 编配密度」共同承载，不能只靠形容词堆砌。
- 概念/修辞/技术范式是情感的载体，**情感先行**；载体束缚情感时调整载体，不调整情感真实性。

## 3. 声线与歌词（模式 A）

- **声线指定**：Prompt 中描述声线特征（如 `deep commanding male vocals`）；自然语言式平台按平台声线选择机制显式指定。
- **视角多样化**：单曲内视角一致；专辑层视角 ≥3 种且第一人称自述 ≤60%（判叙事结构，不判「我」字频率）。
- **短句为主**：一行一意象，可唱性强；避免散文长句。
- **段落标记**：`[Verse]` `[Chorus]` `[Bridge]` `[Outro]` 等；纯音乐用自然语言描述结构变化。
- **歌词格式化**：`()` = 唱（背景人声，跟随主唱声线）；`[]` = 指令（不唱）。切换声线用 `[Female Vocal]` / `[Male Vocal]` 结构标签；不要把声线指令写进 `()`。
- **情绪可及性**：每首含 2-3 个具体感官锚点；陌生听众仅凭歌词能说出情绪来源。

## 4. 器乐情绪叙事（模式 B）

三要素缺一不可：

| 要素 | 作用 | Prompt 体现 |
|------|------|------------|
| 主导乐器 | 情绪代言人 | `piano-led` / `cello-led` |
| 演奏技法 | 情绪叙事手段 | `descends from high register` / `repeated with variations` |
| 和声色彩 | 情绪底色 | `in C minor` / `Lydian mode` / `suspended chords` |

- **纯音乐命名独立**：中文命名，不得复用歌词版曲名的任何元素。
- **人声控制标记**：`Instrumental only, no vocals` 或明确无词人声类型（`wordless vocal pads only`）。
- **乐器克制**：一首一个主导乐器 + 2-3 个配角，不堆砌。

## 5. 技术参数

- BPM、调式、混响、音色、动态五类参数写清。
- BPM 与调式是硬参数；混响/音色/动态可用自然语言描述。
- 甜点区优先（示例 64-76 BPM 抒情区；120-128 BPM 卡点区），具体按赛道 DNA 与实测校准。

## 6. 结构要求

- 时长声明（标签式平台）或时长锚句（自然语言式平台）。
- 前 5-8 秒进主旋律或人声；Hook 清晰可截。
- 加长结构：V-V-PreCh-Ch 反复 + Bridge + 最终 Ch + Outro，副歌 3 次，35-39 行，防「歌词短→生成短」。
- 曲式变体：整张专辑避免每首都用同一段落骨架，目标 2-3 种；BGM/冥想类可豁免。

## 7. 元数据与命名

- 曲名含场景关键词；可搜索、可记忆、避免特殊字符。
- 曲名不受字数限制；判据是「源于生活、高于生活」——从生活现场升维到高级意象域，禁把生活事件名直接当曲名（除非本身有反讽张力）。
- 平台命名优化：搜索性 / 情绪触发 / 语音记忆 / 常见度。
- 纯音乐命名与歌词版独立。

## 8. 文件架构（可配置模板）

每个专辑项目建议包含：

```
<project>/
├── album-index.md    专辑索引：曲目表、情绪/角色/意象、选型依据
├── album-notes.md    专辑说明：氛围关键词、调式速度总表
├── track-*.md        单曲文件：Style、歌词、自检表
└── notes/             参考音频、DNA 报告、调研记录（按需）
```

> 目录名与文件命名可按项目调整；关键是「索引 + 单曲 + 参考」三层可检索。

## 9. 专辑审查

### 9.1 情绪光谱

- ≥3 首专辑必须审查情绪分布；偏色 >50% 需用三方向深化（同情绪不同场景/不同烈度/不同视角）。
- 情绪光谱管情绪**颜色**；留白/密度维度见 `whitespace-craft`。

### 9.2 曲式光谱

- ≥3 首专辑审查：模式 B 查骨架 >50%，模式 A 查动态/时长雷同（软指南，BGM 可豁免）。
- 按情绪从曲式变体菜单选差异化骨架。

### 9.3 声线光谱

- ≥3 首专辑审查男女声比例/对唱/和声；单一性别 >80% 需调和（软指南，模式 B 豁免）。

### 9.4 审查方法

- 硬约束自动修；软指南提出等用户决策；索引一致性逐行比对；字符数用脚本工具化。

## 10. 留白与起伏

- 写词时就构思副歌前静默/句尾消散/密疏布局，不只事后审。
- 详细技法调用 `whitespace-craft`；结构性留白 ≠ 内容压缩。

## 11. 画面感与意象

- 写词时按画面感公式 10 维度主动构建，重点 ⑥比拟 ⑦词性活用。
- 详细技法调用 `imagery-craft`；情绪可及是及格线，画面感是优秀线。

## 12. 洞见、金句、选题、钻石、浓度、开口

- **洞见**：陈述式（一句可复述的话）或叙事承载式（一段走完的路）；跑抽掉/转述/依附三测试。
- **金句**：先选载体族、再造句；具象日常锚点 × 升维载体；峰值位置定稿二选一（递进式/首现式）。
- **选题锚点**：锚定听众经历过的关系/人生时刻；关系槽位/唤醒度/可截句性三测试；物件退为道具。
- **情理钻石**：每曲 ≥2 处情感/哲理亮点，跨段分布；抽掉则段落失光才算；剂量「一点点，不能太多」。
- **浓度**：大词要被具体代价支付；先定形态（烈/静/暖/洞察）再选机制；每段 ≥1 泄漏动作、≥2 身体锚点。
- **开口设计**：V1 首句钩子级（禁铺垫句开场）；副歌首句可截句；前 30-35 秒有声音记忆点。

> 以上自检落链见 `lyric-reviewer` 对应检查点；未实测技法按「先方向后数值」使用。

## 13. 修订纪律

- 企划修订按句子**功能**切分保留清单：参数句（BPM/调式/制作统一句/结构行为句/声明句）可保留；叙事句（场景描述）必须随歌词方向同步重写。
- Style 与歌词是同一个故事的两层表达；歌词换了时代，Style 里讲旧场景的句子就是残留撕裂。
- 多线并行批次：题材域隔离、曲名双向核对、交付通报后才视为可扫描态、数字不一致时各自独立复算并溯源。

# 数据源清单（公开来源）

> **核心原则**：不得自创 URL；新增数据源必须先验证再写入。
> **平台归属**：不同集团的数据源只能作受众侧写代理，报告中必须标注归属，不得混称为核心平台数据。
> **可用性**：公开榜单页面结构会变化；采集失败时按条目兜底，不得臆填。

---

## 核心数据源（短视频系直接）

### 1. 目标平台热歌榜（App 内）

- **访问方式**：目标平台 App 内「热歌榜」TOP 10；部分平台无公开 web 榜单。
- **数据字段**：rank / song / artist / 趋势（↑↓ NEW）。
- **采集建议**：App 内截图记录，或用多源关键词侧写补充；web 端无可读数据时不硬抓。

### 2. 现象级病毒歌曲（多源搜索）

- **数据性质**：定性（无绝对播放量，靠话题热度）。
- **推荐查询词**：
  - `抖音热歌 {YYYY年M月} TOP10`
  - `抖音热门 BGM {YYYY年M月} 卡点 翻唱`
  - `{YYYY年M月} 抖音 神曲 爆火`
  - `抖音 {YYYY年M月} 现象级 神曲`
- **验证来源**：行业媒体深度分析、新闻报道、平台热榜。
- **风险**：政治敏感/鬼畜类按项目内容边界处理。

## 辅助参考数据源（跨平台验证）

### 4. Apple Music China 周榜

- **URL 模板**：`https://www.recotop.com/charts/china/YYYY-MM-DD/`
- **归属**：Apple（第三方归档）。
- **更新频率**：每周一发布。
- **受众画像**：苹果设备付费用户（偏高端、偏老，与短视频受众重合度低）。
- **使用定位**：仅作跨平台共识验证，**绝不能单独下短视频结论**。
- **关键警示**：头部艺人效应在 Apple Music 极强，严禁据 Apple 数据推断短视频受众偏好。

### 5. QQ 音乐热歌榜

- **URL**：`https://y.qq.com/n/ryqq/toplist/26`
- **归属**：腾讯音乐（TME）。
- **更新频率**：实时。
- **抓取难度**：中（SSR 渲染，部分文本可读）。
- **数据完整度**：TOP 20 完整公开，TOP 100 需登录。
- **相关榜单**：新歌榜 `toplist/27`、飙升榜 `toplist/62`、流行指数 `toplist/4`。

### 6. 网易云音乐飙升榜

- **URL**：`https://music.163.com/discover/toplist?id=19723756`
- **归属**：网易。
- **更新频率**：每日。
- **抓取难度**：中（返回大 HTML，需二次提取）。
- **数据完整度**：TOP 100 完整。
- **受众画像**：独立/小众向（年轻文艺用户）。
- **相关榜单**：热歌榜 `id=3778678`、新歌榜 `id=3779629`、原创榜 `id=2884035`、民谣榜 `id=5059661515`、国风榜 `id=5059642708`。

## 年度历史榜单（跨年趋势分析）

- **QQ 音乐年度榜单**：按年份查找官方专题页或权威媒体盘点。
- **网易云年度榜单**：年度音乐奖专题、年度歌单、媒体报道。
- **第三方归档**：Wayback Machine（早期页面备份）、Soundcharts（付费，覆盖多榜历史）。
- **使用建议**：历史纵深调研优先用年度榜；当前爆款捕捉优先用实时榜；两者结合识别「跨年长尾爆款」。

## 数据源失效与陷阱

| 失效/陷阱 | 状态 | 备注 |
|----------|------|------|
| 短视频平台 Open API 热歌榜 | 需 token | 不纳入常规采集 |
| 目标平台 App 内完整榜 | 仅 App | web 端无可读数据时不硬抓 |

## 采集方式与兜底

| 源 | 直接 fetch | 有效方式 |
|---|---|---|
| 酷狗短视频热歌榜 / 飙升榜 | 仅返页脚 | `curl` + 浏览器 UA 取完整 SSR HTML 后解析 |
| recotop Apple Music 周榜 | 丢表格 | 原始 HTML 解析 |
| QQ 音乐热歌榜 | 仅名次+时长 | 同源官方接口取全量 |
| 网易云飙升榜 / 热歌榜 | JS 模板 | 官方接口 `api/v3/playlist/detail` 取全量 |
| 需登录态的榜单 | 空 | 浏览器 CDP（用户登录态），失败则换源 |

- **失效处理**：在本文件标注失效，并在 SKILL.md 同步移除引用。

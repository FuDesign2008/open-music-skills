# 趋势报告模板

> 核心原则：blockquote 元数据、中文编号、表格优先、sources 在末尾；标签式 Prompt 字符数合规。

## 文件命名

- 路径：`<research-dir>/trends/YYYY-MM-DD.md`
- 修订版加 `v2`/`v3` 后缀；日期取调研日期（非数据窗口末日）。

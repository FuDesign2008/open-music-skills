# Style 配方模板（7 类对应，双载体）

> 每个模板给 6 要素：Style 构件 / Sample Style（自然语言式与标签式）/ 歌词主题 / 受众场景 / BPM 调式 / 避坑。
> 标签式 Prompt 必须 ≤ 目标平台字符上限（示例 1000）；自然语言式按平台短指令习惯。
> 模板是起点，不是定稿；按赛道 DNA 与实测微调。

---

## 通用规则

- **结构原则**：声线 → 情绪 → 编配 → 技术参数 → 结构；关键层放开头结尾。
- **关键禁忌**：不引用具体作品/艺人；不堆砌乐器；情绪不靠形容词堆；标签式不超字符上限。
- **自然语言式**：把标签要素转写为中文单段（流派/BPM/声线/编配/时长锚句）。

---

## 类型 1：治愈系赫兹 · 男声民谣

- **Style 构件**：指弹木吉他 + felt piano 铺底 + 轻弦乐 + 温暖男声（半说半唱）
- **标签式示例**：`warm mature male vocal, half-spoken verses, fingerpicked acoustic guitar, felt piano, soft string pad, 82 BPM, G major, warm analog production, immediate melodic hook`
- **自然语言式示例**：「温暖男声，主歌半说半唱，指弹木吉他配柔和的电钢铺底，轻弦乐在后段进入，约 82 BPM，G 大调，温暖模拟质感，开头 5 秒进主旋律」
- **歌词主题**：远方思念、人生感悟；具体场景 + 实物锚点
- **受众场景**：深夜独处、长途车程、疗愈
- **BPM/调式**：75–95 BPM；大调为主
- **避坑**：前奏过长；编曲过满；声线过亮

## 类型 2：燃感最强音 · 女声励志

- **Style 构件**：钢琴动机 + 弦乐铺底 + rock drum kit + belting 女声
- **标签式示例**：`cinematic power ballad, piano motif intro, lush string section, explosive belting female vocal, rock drum kit, 128 BPM, D minor, radio-ready production`
- **自然语言式示例**：「电影感励志流行，钢琴动机开场，弦乐铺底，副歌女声爆发，摇滚鼓组，约 128 BPM，D 小调，电台级制作」
- **歌词主题**：励志燃向、逆风奔跑；避免空喊
- **受众场景**：运动、励志混剪
- **BPM/调式**：120–140 BPM；小调为主
- **避坑**：副歌只有响度没有旋律；大词无代价

## 类型 3：颅内复读机 · 梗歌

- **Style 构件**：短 hook 重复 + 拟声采样 + 留白小节 + lo-fi 质感
- **标签式示例**：`memetic hook repetition, blank bars for remix, replaceable ad-lib slots, lo-fi unpolished aesthetic, playful male vocal, 100 BPM, A minor`
- **自然语言式示例**：「魔性短 hook 重复三到五次，留出空白小节供翻唱，口哨和拍手拟声，lo-fi 不修音质感，约 100 BPM，A 小调」
- **歌词主题**：玩梗、反讽、日常解构
- **受众场景**：UGC 二创、短视频挑战
- **BPM/调式**：95–120 BPM
- **避坑**：梗太窄无传播面；政治敏感

## 类型 4：多巴胺和弦 · 甜感 R&B

- **Style 构件**：电钢 + finger snaps + glockenspiel + 明亮女声
- **标签式示例**：`bouncy electric piano, finger snaps, glockenspiel accents, sweet breathy female vocal, 95 BPM, B-flat major, bright polished production`
- **自然语言式示例**：「轻快电钢，响指节奏，钟琴点缀，甜美气声女声，约 95 BPM，降 B 大调，明亮精致制作」
- **歌词主题**：夏日恋爱、甜宠；物件化甜感，不靠形容词
- **受众场景**：通勤、日常悦己
- **BPM/调式**：90–105 BPM；大调
- **避坑**：甜得腻；结尾告白说破

## 类型 5：岁月金唱片 · DJ 改编

- **Style 构件**：经典旋律 + 0.8x 减速 + 加重低频 + four-on-the-floor
- **标签式示例**：`DJ remix, slowdown version, 0.8x speed, four-on-the-floor beat, enhanced sub bass, nostalgic melody, 115 BPM, G minor`
- **自然语言式示例**：「经典旋律的 DJ 改编，速度降到原版八成，加重低频，四拍电子鼓点，怀旧感，约 115 BPM，G 小调」
- **歌词主题**：怀旧、集体记忆
- **受众场景**：短视频卡点、老歌翻红
- **BPM/调式**：110–125 BPM
- **避坑**：采样未公版录音；只改速度不改音色

## 类型 6：新腔唱古韵 · 国风现代

- **Style 构件**：民乐主奏（古筝/竹笛/二胡）+ 现代编曲 + 戏腔或流行声线
- **标签式示例**：`modern Chinese folk, guzheng and bamboo flute lead, lush strings, subtle electronic pulse, 110 BPM, D minor, warm analog production`
- **自然语言式示例**：「国风现代，古筝与竹笛主奏，弦乐铺底，轻微电子脉冲，约 110 BPM，D 小调，温暖模拟质感」
- **歌词主题**：文化自信、审美升级；当代生活，不是古装场景
- **受众场景**：国风审美、文化内容
- **BPM/调式**：90–120 BPM
- **避坑**：堆古风元素贴皮；古诗词直接拼贴

## 类型 7：锐舞炸场调 · K-Pop EDM

- **Style 构件**：强电子节奏 + 女团/男团声线 + 视觉化 drop
- **标签式示例**：`K-pop EDM, punchy synth bass, four-on-the-floor kick, group chants, 125 BPM, F-sharp minor, loud polished mix`
- **自然语言式示例**：「K-pop 电子，强合成器贝斯，四拍底鼓，群体喊麦，约 125 BPM，升 F 小调，响亮精致混音」
- **歌词主题**：舞蹈挑战、自信宣言
- **受众场景**：舞蹈翻跳、视觉冲击
- **BPM/调式**：120–130 BPM
- **避坑**：核心平台常缺席；不要据辅助平台数据高估

---

## 模板使用流程

1. **选模板**：按 TOP 3 主导类型选。
2. **微调参数**：BPM/调式/声线按报告数据调整。
3. **字符数验证**：标签式 Prompt 必须脚本计数；自然语言式按平台短指令。
4. **写入报告**：每套含 6 要素 + 避坑清单。

## 模板更新策略

- 每期报告后回写有效/无效模板。
- 新模板先小范围验证，再进入默认清单。

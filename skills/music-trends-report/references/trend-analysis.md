# 趋势分析框架（七类旋律 + BPM + 制作签名 + 主题 + 缺口）

> 框架来源：公开行业白皮书（巨量引擎 × WGSN 旋律营销趋势）+ 短视频 BGM 实际消费视角校准。
> **关键校准**：白皮书的「黄金 BPM 120-128」是品牌营销视角；短视频 BGM 实际消费的黄金区更常落在 75-95 BPM。引用白皮书时须标注此差异。

---

## 一、七大旋律类型

| 类型 | 风格特征 | 对应人群 | 典型情绪/场景 | 短视频系权重（方向性） |
|------|---------|---------|-------------|----------------------|
| **治愈系赫兹** | 民谣、白噪声、极简编曲 | 疗愈共情派 | 缓解压力、深夜独处、长途车程 | 绝对主导 |
| **颅内复读机** | 魔性洗脑、强记忆点 | 抽象梗学家 | 幽默解构、玩梗、UGC 二创 | 病毒层主导 |
| **多巴胺和弦** | 元气流行、甜感音乐 | 快乐寻宝人 | 积极、悦己、日常通勤 | 稳态 |
| **锐舞炸场调** | 强节奏电子 / K-pop | 潮流律动党 | 舞蹈挑战、视觉冲击 | 结构性缺席（辅助平台常高估） |
| **岁月金唱片** | 经典翻唱、复古 Disco | 时光旅行者 | 怀旧、集体记忆、节日场景 | 偏弱（老歌翻红 + DJ 改编） |
| **新腔唱古韵** | 民乐 + 现代编曲 | 国风新主理 | 文化自信、审美升级 | 常缺位（蓝海机会） |
| **燃感最强音** | 摇滚、交响、史诗配乐 | 激情效能党 | 运动自律、爱国情怀、励志 | 长青 BGM |

**分类原则**：一首歌归一类（边界模糊取主导特征）；DJ 改编版归「岁月金唱片」；戏腔电子混合归「新腔唱古韵」。

## 二、BPM 区间分析（短视频 BGM 视角）

| BPM 区间 | 对应类型 | 备注 |
|---------|---------|------|
| **75–95 BPM** | 治愈民谣 / 都市抒情 | **主流黄金区** |
| 90–105 BPM | 多巴胺 R&B / 轻快流行 | 甜感 |
| 100–120 BPM | 魔性洗脑 / 梗歌 | 颅内复读机 |
| **110–125 BPM** | DJ 改编 / 减速版（0.8x） | 短视频特有现象 |
| 120–128 BPM | 卡点舞蹈（白皮书推荐） | 实际占比常低于白皮书宣称 |
| 125–140 BPM | 燃感励志 / 说唱 | 励志 BGM |

**双峰分布**：峰 1 = 75–95 BPM（抒情治愈，主流）；峰 2 = 120–128 BPM（卡点锐舞，小众但存在）；谷 = 100–115 BPM（常为机会窗口）。

**结论**：为短视频/流媒体受众创作，优先 75–95 BPM；卡点舞蹈向 120–128 BPM 仍可，但不是主流。

## 三、5 个常见制作签名

### 签名 1：指弹木吉他 + felt piano 铺底

- 适用：治愈系赫兹
- 要点：木吉他 fingerpicking（不是 strumming）；felt piano 软锤处理；间奏加大提琴低频
- 标签式关键词：`fingerpicked acoustic guitar`, `felt piano`, `melodic cello underpinning`

### 签名 2：温暖男声 + 半说半唱

- 适用：治愈系 + 部分燃感
- 要点：主歌 half-spoken / half-sung；略带沙哑；副歌清亮延伸
- 标签式关键词：`warm mature male vocal`, `half-spoken verses`, `slight rasp`, `intimate conversational`

### 签名 3：DJ 改编 / 减速版（0.8x）

- 适用：岁月金唱片（老歌翻红）
- 要点：速度降至原版 80%；加重低频；加电子鼓点（four-on-the-floor）
- 标签式关键词：`DJ remix`, `slowdown version`, `0.8x speed`, `four-on-the-floor beat`, `enhanced sub bass`

### 签名 4：励志弦乐 + 高音女声

- 适用：燃感最强音
- 要点：钢琴动机 4 小节前奏；预副加 string section；副歌 rock drum kit + belting female vocal；bridge 假音转换
- 标签式关键词：`cinematic power ballad`, `lush string section`, `explosive belting chorus`, `false voice transition`

### 签名 5：魔性重复 hook + 留白

- 适用：颅内复读机（梗歌）
- 要点：hook 短句重复 3-5 次；留出空白小节（供翻唱填词）；拟声采样（口哨/拍手/笑声）；不修音准（pitch imperfections retained）
- 标签式关键词：`memetic hook repetition`, `blank bars for remix`, `replaceable ad-lib slots`, `lo-fi unpolished aesthetic`

## 四、歌词主题密度

| 主题簇 | 代表意象 |
|--------|---------|
| **远方 / 离别 / 思念** | 远方、绿皮火车、十年后的同学会 |
| **人生感悟 / 自我对话** | 人生路漫漫、向云端、可能、星辰大海 |
| **童年 / 成长怀旧** | 我记得、骄傲的少年、外婆家 |
| **爱情释怀** | 恋人、阴天、为爱痴狂 |
| **玩梗 / 反讽** | 老板又说加油、地铁又挤了、游戏道具拟人 |
| **励志 / 燃向** | 逆风、奔跑、黎明前的黑暗、不被定义 |

**主题选择建议**：
- 短视频系首选：远方思念 + 励志燃向 + 玩梗反讽（三联结构）
- 次选：童年怀旧 + 爱情怀旧
- 避开：纯都市寂寞（偏 Apple 受众）、纯政治讽刺（项目禁入）

## 五、缺口识别（必做）

每期报告必须明确列出 **3-5 个缺口类型**，并评估切入价值：

| 缺口判定标准 | 说明 |
|------------|------|
| 在 TOP 20 中数量 ≤1 | 弱信号类型 |
| 在核心平台完全缺席 | 结构性缺位 |
| 仅有 1-2 个标杆案例 | 蓝海候选 |

**切入价值评估维度**：市场规模、竞争强度、AI 原生适配度、投入成本；结论必须是「值得/谨慎/禁入」之一。

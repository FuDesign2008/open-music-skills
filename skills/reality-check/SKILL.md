# reality-check · 实物常识核查（创作链强制检查门）

> **立规案例**（创作者纠偏）：某次甜歌创作中，AI 调研给出的曲名候选把一种串状食物写成「一颗」，词稿又安排「揣兜里、留到明天」——三重常识硬错误：①串状物按**串**卖按**串**吃，不存在「一颗」的单位；②带签/易碎物不能揣兜（真实携带=纸罩或纸袋拿在手里）；③现做现吃类食物**不能隔夜**（会化/变硬，且有食安风险）。纠偏后改为块状食物 + 当天动作链（同源内核保留，物件与动作链全部换正）。
>
> **为什么核查不等于扫兴**：常识错误不入耳——听众 1 秒出戏（「串状物哪有一颗的？」评论区就塌了）；而意象升华恰恰要踩在**可靠的地面上**才升得动——「把路灯走完」是诗，「一颗烤串揣兜里」是错。核查守的是物理行为链，放开的是意象翅膀。

## 一、何时触发（写前、采纳时、终检前）

| 时点 | 动作 |
|---|---|
| **选物件后、动笔前** | 跑三问 + 幻觉诱捕（第二节），有疑点先追调再动笔 |
| **采纳 AI 调研候选时**（曲名/意象/技法/数据） | 逐条溯源分级（第三节）——AI 产出候选=猜测，不是素材；**转述≠证据** |
| **生成前总检查前** | 对歌词内全部实物动作链做最后一遍三问扫描（虚字、抒情、纯比喻不过机，只查实物与动作） |
| 创作者反馈「不对劲/不真实/有硬伤」时 | 先跑本 skill 定位，再改稿 |

## 二、三问核查法（每个实物物件过一遍）

对歌词/曲名里的每个实物物件问：

1. **计量与形制**：它按什么卖/怎么计数？（按串/按块/按双/按瓶/按个）单体是什么样？（「一颗烤串」❌ vs 「签子上剩一颗」✓）曲名/歌词的用量词是否站得住？
2. **使用动作链**：怎么拿（揣兜/捧手/抱怀里/戴）？怎么吃/用（咬/剥/撕/掰/拧）？动作有顺序吗（外壳→果肉；先酸后甜）？每一步写成画面后，听众能否想象出真人真做？——**想象不出真人做的动作链 = 该物件的课文级骨架被写错或被架空**
3. **保存与时限**：能放吗？能隔夜/隔周吗？会化/塌/软/碎吗？「留到明天」类延迟叙事必须过这一关——**现做现吃类物件（烤串/热甜品/花）承担不了隔日承诺**；要写延迟，把延迟半径收进物件真实寿命内（如「最后一颗等到楼道口」= 当天分钟级）

三问全过 → 物件可用；任一问存疑 → 先追调（web/百科/视频实证），再回来写。

## 三、溯源等级（采纳外部候选的闸门）

| 级别 | 来源 | 处置 |
|---|---|---|
| **A 实锤** | 官方/监管/新闻一手（权威媒体/监管部门/品牌官方）/多源互证 | 直接可用 |
| **B 高共识** | 两家以上独立 AI/搜索同向一致，且无外部文献 | 可用，标「共识待实物复核」 |
| **C 单源推测** | 单一 AI 产出、无出处（如某模型给的曲名候选） | **禁直接入稿**——须三问自查 + 至少一次独立检索验证后方可 |
| **D 转述** | 上游对话/历史文档的二手断言 | **禁直接采信**——溯源到一手（「转述≠证据」；曾出现验收环节的大体积幻觉事故） |

**纪律**：AI 调研（豆包/Kimi/DeepSeek 等）产出的是**假设与候选**，不是素材库——每条入稿前按三问+溯源走一遍；调研报告里写明哪些是 A/B/C/D 级。

## 四、幻觉诱捕清单（本品类 AI 最高频常识幻觉）

1. **计量错位**：串状物按「颗」卖（烤串/糖葫芦/冰糖葫芦）；成对物按「个」（手套/鞋/耳环）；罐装按「杯」
2. **保存错位**：给现做现吃类物件写「留到明天」（烤串/热可可/烤红薯凉了变硬——要写延迟先查寿命）
3. **携带错位**：尖锐/易碎/带汤物「揣兜里」（竹签/烧饼带炉温/汤面）；正确写「纸罩好拿在手里/怀里/袋里」
4. **截流反噬**：为搜索词硬造词形（真物件词=可搜索，但词内动作必须与该物件匹配——蹭名「春涧」写《秋涧》可以〔曲名层虚指〕，词内写「啃」烤串就不行）
5. **价格/数量精确化**：无来源不写具体价格/重量/成分数字（写了就成一槌定音，错了就成硬伤）
6. **季节反事实**：夏物件入冬词（西瓜/冰棍与烤红薯共存无碍〔不同行段〕，但同段混季要自查）

## 五、判定分级与处置

| 级 | 含义 | 处置 |
|---|---|---|
| 🔴 | 常识硬错误（计量/保存/携带/动作链断） | **阻断——不进入生成**；给出修正方向（同内核换物件或换写法），由创作者决定具体改法 |
| 🟡 | 待实测项（低频字/口语调/小细节） | 留痕，进歌词文件「发布注记」+ 听核清单 |
| 🟢 | 通过 | 记录三问结果一行（「串状物→串计量✓/纸罩携带✓/现做现吃✓」式） |

## 六、实例卡（串状食物三错 → 块状食物重写）

| 错误写法（v1 词稿） | 为什么错 | 修正后（v3） |
|---|---|---|
| 《兜里还有一颗烤串》 | 烤串按串卖，带签不能进兜 | 《掰开红薯的那一下》（块计量+真实动作） |
| 「咬一颗揣兜里 / 放回纸袋卷好口」 | 单颗脱离签子会沾油/不成形 | 「走到楼下才吃完 / 焦皮捏了一手黑」 |
| 「留给明天下班的路」 | 现烤现吃，隔夜变硬+食安风险 | 「站在摊边趁热吃」（延迟=当天分钟级） |
| 洞见层（等待/期待主题） | （无伤，保留） | 内核可迁移，载体必须入库核查 |

## 七、与其他检查的关系

- 与 `imagery-craft`：imagery 管意象升维（画面感公式），本 skill 管**升维前的地面**——物理行为链。先过本 skill，再上天
- 与 `lyric-reviewer`：reviewer 管诗性/审美质量；本 skill 管事实底座——两者独立跑，🔴 由本 skill 判
- 与 `ego-multi-ai-research`：AI 调研是本 skill 最大的幻觉供体（案例即调研候选）——调研产出必经第三节溯源闸门
- 与证据驱动原则：本 skill 是其在**创作实物域**的落地形式

# remix-craft · remix/老歌新编创作技法

> **定位**：把老歌/公版素材做成当代作品——公版过审、做减法、情感借鉴、真实素材四条技法。
> **合规前提**：仅用公版词曲（作者死后 50 年，合作作品取最后死亡者）；**绝不采样未公版录音**，全部重新生成；平台版权过滤/内容审核以当前平台规则为准。

## 何时用本 craft

- 做 **remix / 翻唱 / 老歌新编 / 公版歌 / 致敬改编**
- 用户反馈「创意猎奇 / 老歌韵味被破坏 / 主歌单薄 / 歌词套路 / 概念刻意」
- 涉及**公版歌曲**（需过平台版权过滤 + 合规判断）

## 4 条核心技法

### 技法 1：公版过审范式

**平台机制**：不同平台的版权过滤阈值不同，且会变化。较宽松的实测经验是——**只有整首歌几乎全部歌词都是原句照搬才可能触发**；个别原句点缀、局部引用、甚至副歌整段原句都可能安全。不是「任何原句必拒」，也非线性「大段比例」。保守的「零原句」判断会白白放弃公版名句的熟悉感红利（名句是听众入耳锚点）。

> 具体阈值以**目标平台当前规则**为准；本 skill 给的是创作范式，不是平台承诺。

**范式**：
```
公版曲名（蹭搜索热度，曲名通常不过滤）
  + 主歌原创（避开歌词过滤）
  + 副歌公版原句点缀（38-40% 为听感黄金比例甜区，非过审上限）
  + bridge 和谐（主副歌情感连接）
```

**合规**：仅用公版词曲；**绝不采样未公版录音**，全部重新生成——标签式平台重新生成，自然语言式平台也重新生成。

**选曲优先级**：「公版=安全」不成立——民歌的"集体创作"流传版本可能含**当代整理者**的填词/编曲（其著作权独立计算，可能远未过期）。选曲按干净度排序：

1. **个体作者明确且已公版**（词曲作者生卒分别查、合作取晚者 +50 年）——最可靠
2. **民歌原型**——必须独立核**整理者**（采集/改编/填词命名者）生卒，「集体创作=公版」是危险假设；基于原型重编、署「传统民歌，改编自民间」
3. 影视金曲/近现代创作——词曲作者多未公版（合作取晚者常到 2040s–2070s），直接排除

> 实例教训：某民歌的流行版由 1950 年代整理者填词命名，整理者著作权独立计算、且曲名可能已被注册商标——凭先验把「民歌原型」当公版，险些造成侵权。逐首核实整理者权，不靠笼统归类。

### 技法 2：中式当代民谣做减法（老歌 remix 美学）

**问题**：猎奇风格碰撞（赛博/Trap/后朋克 × 老歌）破坏老歌中式韵味；刻意概念反差（2077/卖命）博眼球用力过猛。

**做减法**：
- **去概念锚点**（无跨时空/反差博眼球的"古今对话/2077/赛博"等外加概念）
- **去硬风格碰撞**（无赛博/Trap/后朋克等破坏韵味的硬碰撞）
- **真诚具体**（当代真实情感、感官锚点，不套路）
- **精致编曲**（木吉他/钢琴/古琴/弦乐，温和现代）

**甜区**：和谐的新意 + 自然真诚 + 精致编曲（既非平也非猎奇）。
**反例**：整批「赛博送别/Trap 康定/后朋克卖报」式全面突破——风格猎奇 + 概念刻意，韵味被破坏。

### 技法 3：借鉴现代热歌匹配（丰富主歌细节）

**做法**：每首**借鉴一首现代热歌的情感内核**，丰富主歌意象。词全原创，**不用原句原曲**（现代热歌多未公版，照搬=侵权+平台过滤）——「情感致敬」非「作品融合」。情感不受版权保护，表达才受保护。

**流程**：
1. 按本曲情感选匹配热歌（离别/爱情/乡愁/奋斗/异地等）
2. 提炼情感内核 + 关键意象（如「细水长流」「平凡人的路」「想见的念头」）
3. 用**原创词**借鉴表达，嵌入主歌/PreChorus/Bridge

**价值**：站在已验证的「情感共鸣点」上，主歌更易打动人；给创作情感锚，避免空洞。
**合规**：借鉴情感非原句原曲；标签式平台仍可写 `original composition`；自然语言式平台按平台规范声明原创。

### 技法 4：调研血肉（主题涉真实议题时）

**做法**：主题涉及真实社会议题/群体时（劳动者/漂泊/异地/疾病…），**先调研真实素材**（新闻/纪实/自述，用权威源），提炼具体意象入词，避免空洞抒情。

**约束**：调研用权威源；意象入词做感官锚点；不直接搬运他人原句。

## 配套：加长结构

remix 歌曲同样需要饱满结构——V-V-PreCh-Ch 反复 + Bridge + 最终 Ch + Outro，副歌 3 次，35–39 行。公版 remix 场景：副歌公版原句占 **38-40%（听感黄金比例甜区）**——副歌 ~38% + 主歌 ~62% ≈ 黄金分割 0.382:0.618，听感最佳。注意 38-40% 是**听感甜区非过审上限**——过审阈值以平台当前规则为准（整首全原句才可能触发）。

## 自检清单（remix 创作）

- [ ] 公版状态已核（词曲作者生卒取晚者 +50 年；**民歌额外核整理者生卒**；曲名商标已在目标市场核查；选曲优先级见技法 1）
- [ ] 不采样未公版录音（全部重新生成）
- [ ] 副歌原句点缀（38-40% 为听感甜区，非过审上限；整首全原句才可能触发）
- [ ] 做减法（去猎奇概念 + 去硬碰撞，真诚精致）
- [ ] 借鉴热歌情感（不用原句原曲，情感致敬）
- [ ] 主题涉真实议题时调研血肉（权威源 + 感官锚点）
- [ ] 加长结构（饱满 4 分钟）

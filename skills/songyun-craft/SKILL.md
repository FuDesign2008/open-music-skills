# 宋韵美学：用宋的方式看当代生活（songyun-craft）

## 核心

**宋韵 ＝「以理性精神为底，用极简克制的手法，追求一种平淡之中见深远韵味的雅致境界」**——**底**（为什么）＝理学思辨的思想地基（格物）｜**手法**（怎么做）＝简素＋克制｜**境界**（通向哪）＝平淡×韵×雅。速记口诀＝**简**（少而精）·**淡**（低温）·**韵**（说一半）·**常**（日常当仪式）。

> **定位**：审美机制，**不是古风元素**——题材永远是今天。本 skill 是操作入口：八测试自检＋六组技法速查＋执行纪律＋警示扫雷。需要更深依据时，按组索引自建扩展阅读。
> **纪律**：① 零古诗词引用／化用；② 当代生活（年轻化、合作署名）；③ 载体升维。**不适用**：燃曲／战歌、甜歌线。**状态**：v0·全部技法未实测——【待实测】项按单变量首夜校准后放量。

---

## 流程（四个动作）

1. **定组**——每首认领 1–2 组（§二）；其余变量固定：声线／BPM／调式／词量门／曲式骨架。
2. **写词**——对应组词层 → 按 §二 的抓手展开。
3. **写 Style**——对应组声音层（【待实测】项标注）→ 按目标平台的 Style 配方规范落位；若平台在生成后锁定音频、不可替换，Style 定稿即终稿。
4. **自检**——§一 八测试 → §四 警示 → 引用式接线写进歌词文件头部。

## 一、八测试（写完全曲必跑；Warning 级——拦「贴皮、跑偏、闷死」，不拦创作）

| # | 测试 | 问法与判绿 |
|---|---|---|
| T1 | 简素 | 删一半还成立吗？——意象域 ≤2 族、音色族 ≤3；删一件就塌＝密度虚 |
| T2 | 枯淡 | 抽掉高潮段还有听头吗？——表面素净、底下有暗劲（悬着的意象／没说完的事）；无事可悬＝枯淡 |
| T3 | 韵 | 十分钟后还剩什么没说破？——转述只说九成、留一分给听众；**说清认知（洞见），不点破情感（韵）** |
| T4 | 张力 | 留白处「带电」吗？——悬置的和声／没落下的节奏指针／悬着没答的话；只空不通电＝空闷 |
| T5 | 直述·听写 | 直抒句标出来——直述 ≤1 处；至少一处情绪由**声音事件**承载（雨打窗／水开了两次） |
| T6 | 换物·痕 | 换掉核心物会塌吗？——物＝证物（换不掉）＋有痕（磨亮的刀柄＞崭新的刀） |
| T7 | 哼唱 | 第一遍副歌后能跟着哼吗？——旋律平易；零门槛白话（需解释的词 ≤2）；hook 要能被抄走 |
| T8 | 开片 | 有一处「故意的不完美」吗？——留毛边、不修补；缺陷必须天生（刻意做旧＝矫情） |

## 二、六组索引（每首认领 1–2 组；组↔测试：一→T1/T4｜二→T2｜三→T3/T4｜四→T6/T5｜五→T7｜六→T8）

| 组 | 命题 | 抓手 |
|---|---|---|
| 一 · 简素 | 少而精 | 乐器 ≤3、一件主导；主意象 ≤2 族；留白两布局（平远式／边角式） |
| 二 · 平淡 | 低温 | 反向动态：副歌收着唱、终段最轻；低能量动词；越浓处越省 |
| 三 · 韵致 | 说一半 | 说一半、不点破；和声悬着不解决；尾奏——归要真、落要轻 |
| 四 · 日常 | 日常当仪式 | 仪式动作引擎；一物到底带痕；物做动作人做受事；双写（具象锚点 × 升维载体） |
| 五 · 雅俗 | 雅俗并置 | 复沓放心用；雅放编曲留白，俗放副歌记忆点（hook 底线不动） |
| 六 · 开片 | 不完美之美 | 留一处毛边不修补；终副歌不拉高反而放轻（缺陷必须天生） |

## 三、纪律

- **单变量**：每首 1–2 组；声音层与词层不同轮动——两层同动＝归因不清。
- **声音层写进生成前**：若平台在生成后锁定音频、不可替换，Style 定稿即终稿；生成走目标平台的生成配方。
- **首夜校准**：每辑 ≤1–2 样本、人听后放量——民乐音色／采样描写／悬置残响先行【待实测】。
- **配套照旧**：合作署名；曲名走 `hit-pattern-craft`。
- **分工与边界**：`whitespace-craft`＝人声缺席工程线（变量隔离）｜`xiaoyao-craft`＝丧失后的淡（辨异）｜`sweet-craft`＝甜感线｜`orchestration-craft`＝配器丰满向（本线是其有意反极）。

---

## 四、警示与红线

1. **理趣说教**——必过依附测试＋代价在场律；全曲 ≤1 处；首轮缓行。
2. **贴皮古风**——加古琴 ≠ 宋韵；机制可以零古乐器成立。
3. **枯淡误读**——静默必须带电（T4）；平淡是曲线的设计选择，不是单调的借口。
4. **与 xiaoyao 辨异**——自足淡 vs 丧失淡：情感底色必须分开。
5. **与 whitespace 隔离**——两条线同跑时先隔离变量：留白只动结尾一处作对照；大面积留白结构另行独立验证。

**红线**：题材=今天，视角／密度／余量=宋——绝不写成宋代场景／古人生活；零古诗词引用／化用。

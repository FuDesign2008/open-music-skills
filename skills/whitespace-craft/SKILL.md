# 音乐留白 = 人声缺席的时段

> **定位**：把「留白」从「静默」扩格为「人声缺席的时段」，服务 AI 音乐创作中「想让歌曲器乐主导、人声稀疏」的需求。是 `music-creation-workflow` 的创作增强层，与情绪光谱、概念服务情感原则互补。
> **依据**：平台结构标签行为的多源确认 + 创作者实测经验。原 silence 留白调研已内化为本文的「静默填充」子选项。
> **平台适配注记**：不同平台对留白指令的支持程度不同——支持结构标签的平台可直接用 `[Intro]` / `[Instrumental]` 段标；不支持或未知的平台，以 **Style 自然语言器乐指令 + 时长锚句**为主通道。方法（人声缺席=留白）平台无关。

---

## 一、核心心法：留白 = 人声缺席的时段

**关键洞察**：对歌唱歌曲，听众的注意力被人声牵引。**人声退出 = 注意力的留白**。这与国画「计白当黑」异曲同工——画面的留白是未落笔处，歌曲的留白是「未唱出」（人声缺席）处。

> Miles Davis: "It's not the notes you play, it's the notes you don't play."——决定一首歌留白的，正是人声没唱的那些时段。

**两种填充**：人声缺席的时段，可以填两种东西——

| 填充类型 | 内容 | 适用 |
|---------|------|------|
| **器乐填充**（重心）| 有节奏的纯音乐段 | 前奏/尾奏/间奏，撑占比 |
| **静默填充**（传统留白，可选）| silence / 停顿 / 消散 | 段落内呼吸、副歌前蓄势 |

→ **留白不等于安静，留白等于「没人唱」**。一首歌人声塞满，即使编曲稀疏也拥挤；大段纯器乐即使节奏强劲，因人声缺席而成为留白，给听者呼吸。

## 二、参考标准（经验性，实测为判据）

> ⚠️ 这是**创作者实测标准**（经验值，非平台官方能力）。多数 AI 音乐平台无法精确保证占比与时长，只能逼近 + 生成后验证。

> **弱控制平台注记**：若目标平台无法精确控制占比/头尾器乐时长，本标准为**软目标**——生成后以听感或音频分析核验；未达标不阻断发行，交作者判断。

- **开头 ≥30s 纯器乐节奏**（前奏，人声晚进）
- **结尾 ≥30s 纯器乐节奏**（尾奏，人声早退）
- **全曲人声缺席占比 ≥60%**——人声是点缀，器乐/静默是主体（两种填充都计入）

**换算**（以 3 分钟为例）：开头 30s + 结尾 30s = 60s 人声缺席；中段还需约 50s 器乐间奏，才能让总缺席 ≥60%（108s）；人声唱词 ≤40%（≤72s）。

> **时长与占比的张力与取舍**：部分平台的时长≈**词量驱动**（词少→曲短），与「人声缺席 ≥60%」（指向少唱）存在机制张力；标准注入模板又常含「完整演唱全部歌词」指导，与「大段没人唱」直接拉扯。取舍口径：
> 1. **时长与占比不可兼得时**，优先保「器乐在场感」的听感目标，时长按实际产出重定标；
> 2. **删除「完整演唱」模板句**并替换为器乐三件套指令后，实测时长不缩反稳——省下的时间轴被器乐段吃掉，人声密度显著下降、空气感提升；
> 3. **无后期补救的平台**（音频预绑定不可替换）——器乐段未生成**只能重送或降级接受**，不能剪、不能补。

## 三、落地：用标签造人声缺席段（含无段标平台对应物）

`[Instrumental]` 系列标签是造人声缺席段的**主战场**（`[]` = 结构指令、不唱）：

| 目标 | 标签 / Style 写法 |
|------|----------------|
| 开头器乐段 | `[Intro]` 段内不写词；Style `long instrumental intro, vocals enter late` |
| 结尾器乐段 | `[Outro]` 段内不写词；Style `extended instrumental outro` |
| 中段间奏 | `[Instrumental Break]` / `[Instrumental]`；Style `extended instrumental midsection` |
| 全局占比 | Style `instrumental-heavy arrangement, vocals sparse, long instrumental passages` |
| 歌词框留空 | 不写词的段落留空行，平台自动填器乐 |

> **无段标平台对应物**：上表全依赖段标行为；若目标平台对段标的识别未知或不可用，落地 = **优先用 Style 自然语言句描述器乐段 + 时长锚句**（不依赖段标识别）。

| 目标 | 自然语言 Style 写法（中文） | 可靠性 |
|------|------------------------------------|--------|
| 开头器乐段 | 「前奏用纯器乐铺陈约三十到四十秒（配器点名两件），人声晚进」 | ✓ 实测生效；数值按平台校准 |
| 结尾器乐段 | 「尾奏以器乐收束，人声早退（约三十到四十秒）」 | ✓ 实测生效；数值按平台校准 |
| 中段间奏 | 「段落之间留出纯器乐过门——主歌之后与末段副歌之前各一处、每处约十五秒」 | ✓ 单处实测生效；双过门待校准 |
| 全局占比 | 「主唱句子之间留呼吸，不要把每小节填满」＋词量压到留白窗 | **✓ 实测生效**（字/秒显著下降） |
| 段标类方案（`[Intro]` 留空 / `[Instrumental]`） | 段标注入后产出正常，但段标是否被识别为器乐段/是否被唱出**待听感确认** | 待实测经验项 |
| **（…）舞台括号行** | ⚠️ **不要注入**——「（前奏器乐 25-30 秒…）」类行与 Style 指令**冗余**且有**被唱出风险**（行内阿拉伯数字最危险）；留白信息只走 Style 一个通道，括号行仅留在工程稿作人读注记 | **✓ 实测规避** |

**留白模板配方（进阶档）**：

1. **Style 指令骨架**——三段式：`{流派系}…，{声线}…，约 {BPM} BPM，{调式}。**前奏用纯器乐铺陈约三十五到四十秒（配器点名两件），人声晚进；段落之间留出纯器乐过门，主歌之后与末段副歌之前各留一处、每处约十五秒；尾奏以器乐收束，人声早退（约三十到四十秒）。**核心配器三件：…。句间留呼吸，主歌收着唱；副歌不满铺；桥段撤到人声与吉他。近场混响节制。时长撑到 3 分 30 秒左右。`
2. **必须删除的旧句**：`完整演唱全部歌词，不要省略段落`——这是歌词过密的**直接病因**（强制人声填满每小节）。
3. **词量窗（留白档）**：总 CJK **400-440**；**纯唱词 340-380**（剔除舞台行后）。**词量窗收紧时的取舍优先级＝先舍白描填充句、永不砍承重句**——词可以少，句句要贵。
4. **注入稿只放纯唱词**：`（…）`舞台行与段落间内联行**一律不进 inject 文件**（Style 已全量描述器乐段，括号行只增演唱风险）；`[Instrumental Break]` / `[Bridge]` 等段标保留（作结构提示）。
5. **结构建议（复沓减一）**：副歌三复沓改两复沓——中段第二次副歌位由**器乐变奏段**承担（词省、器乐增）：`[Intro]→V1→PC1→C1→[Instrumental Break]→V2→PC2→（器乐变奏·原 C2 位）→[Bridge 器乐独白]→FC→[Outro]`。
6. **注入头话术**：`曲名定为《X》。请直接使用下方确认的歌词与风格为这首歌谱曲演唱。这首歌刻意留白：前奏人声晚进（约三十五到四十秒纯器乐）、段落之间留出两段纯器乐过门（各约十五秒）、尾奏人声早退（约三十到四十秒器乐），主唱句子之间留呼吸，不要把每小节填满。段落标签作结构提示，不要把标签唱出来。`
7. **验收判据**：生成时长达标且器乐段听感成型；**双候选选时长长者**（器乐段越成型时长往往越长）；生成后**快听前 40 秒与尾部**确认器乐段真生成——耳朵为最终判据。
8. **已知边界**：时长锚句保持「3 分 30 秒左右」（「3 到 4 分钟」会反向推词量门让引擎唱更多词）；数值需按平台校准。

**档位关系**：标准档（正常词量驱动）↔ 留白档（少唱多器乐）。两档非替代关系——窄 BPM / 冷门流派或时长承压时可回落标准档并注明。

**要诀**（实测教训）：

1. **标签是提示不是保证**——精确 30s/60% 控不了，靠多版本选优 + 后期剪辑补足（无后期通道的平台：重送或降级接受）
2. **Style 是主战场**：自然语言长描述比零散标签更能驱动器乐段
3. **生成后必验证**：器乐段是否真生成、占比是否达标（听辨计时 / RMS 深度低谷）。失败重送，或走后期（分轨删人声造器乐段）——无后期通道的平台不适用

## 四、技法：规划人声缺席时段

### 核心手段（撑占比）

1. **开头结尾器乐段**——硬标准 ≥30s，用 `[Intro]` / `[Outro]` 框定
2. **中段器乐间奏**——verse 与 chorus 之间插 `[Instrumental Break]`，撑满 ≥60%
3. **乐器 drop in/out**——器乐段内一次只让一件乐器主导，制造空间感
4. **渐进累积**——器乐层从少到多逐层加厚，末段填满

### 填充子选项（人声缺席处填什么）

- **器乐填充**（默认/重心）：有节奏的纯音乐，撑占比
- **静默填充**（可选，传统留白）：音符消散入寂静（`notes fade into silence`）、段落间 void、副歌前战略性停顿。注意 `[Silence]` 单用实测不可靠，短停顿改用 `_ _ _ _ _` 下划线占位
- **单件器物独白**（第三选项）：空隙交给**一件乐器独奏**——独奏段＝物在说话（一件乐器＝一件器物，「像一件老物件在说话」）。与器乐填充的区别：器乐填充是泛配器撑占比，本选项把主导收窄到单件器物音色——适合日常／器物题材

### 配套：tension-release（让器乐段有方向）

光有大段器乐会「空」，需配 tension 让其蓄势：

- 和声悬而未决：sus4 / 七和弦 / `suspended chord unresolved`
- 切分：`syncopation` / `hits slightly off the beat`
- 动态反差：`whisper-soft verse explodes into loud chorus`
- tempo drag：`slight drag before the chorus, snaps back on the downbeat`（平台只能近似）

> **「间」的带电判据**：留白段（人声缺席处）必须**带电**——空隙里要有悬置的和声、没落下的节奏指针、悬着没答的话（空是「充满紧张的时间与空间」，不是空白）。只空不通电＝**空闷**（听众没有补完的欲望），不是留白——上方 tension-release 手段正是给留白通电的落地。

## 五、取气两派 → 人声占比定位

中国画两大留白流派，正可映射到人声占比：

| 流派 | 特征 | 人声占比 | 适用 |
|------|------|---------|------|
| **密处取气** | 满密，留白极少却珍贵 | 人声多、器乐少（<60% 缺席）| 人声密集型燃曲 |
| **虚处取气** | 大量留白，笔墨极简 | 人声少、器乐多（>60% 缺席）| 器乐主导型，合 ≥60% 标准 |

→ ≥60% 标准**倾向虚处取气**。一张专辑可交替布局密处/虚处取气曲目，制造整体呼吸（这是情绪光谱的**密度维度**补充：光谱管情绪颜色，本 skill 管人声/器乐密度）。

> **宋画两布局**（二选一）：**平远式**（远景铺底缥缈，逐层淡出）／**边角式**（主角偏居一角，大面留空，一件乐器独撑）。与取气两派分属两个轴：取气两派管**占比定位**（留白多少——本 skill 主线），两布局管**构图形态**（留白怎么分布）——可叠加使用。

## 六、创作工作流

> **重要区分**：本 skill 的解法是**结构性留白**（调整器乐/人声的时间分配），**不是内容压缩**。默认不改动已有歌词；若本曲按「留白档」词量窗创作（见 §三 第 3 条），那是在排版层主动选择更小的词量档——收紧词量窗时按该条的取舍优先级处理（先舍白描填充句、不砍承重句），而不是为留白把想说的话砍掉。

```
1. 定人声缺席比例（默认 ≥60% + 开头结尾各 ≥30s）
2. 规划开头结尾器乐段（[Intro] / [Outro]，Style 描述）
3. 规划中段器乐间奏，撑满占比（[Instrumental Break]）
4. 人声段落 ≤40%：短句为主（人声是点缀不是主体）——不靠删内容，靠句长与行数排布
5. 配 tension 让器乐段蓄势（sus4 / 切分 / 动态反差）
6. 落地：标签 + Style 自然语言（无段标平台：Style + 时长锚句）
7. 生成后验证：器乐段真生成？占比达标？失败重送或后期补足（无后期通道：重送或降级接受）
```

## 七、各流派器乐占比模板

| 流派 | 器乐占比套法 | Style 关键词 |
|------|------------|------------|
| **器乐主导流行** | 虚处取气：长前奏尾奏 + 多段间奏，人声晚进早退 | `instrumental-heavy, vocals enter late and leave early, long passages without vocals` |
| **治愈民谣** | 虚处取气：木吉他主导器乐段，句尾消散 | `sparse acoustic, long instrumental sections, vocals sparse, notes fade` |
| **情感电子/drop** | 人声段密 + build-up/drop 虚：build-up 去层 → drop 爆发 | `extended instrumental build-up, vocal drops out before drop, sudden full-band drop` |
| **古风/国风** | 虚处取气：器乐段即「意境」，单乐器（古琴/箫）主导大段 | `sparse traditional instruments, long instrumental passages, vast space between vocals` |
| **燃曲/战歌** | 密处取气：人声密集，器乐段只在副歌前抽 kick | `dense powerful arrangement, vocals dominant, instrumental break before climax` |

# 逍遥丧失美学：用失重飘散表达「不复逍遥」（xiaoyao-craft）

> **定位**：把「逍遥的丧失」发展成可复用的 Suno 声音美学，专注声音本体（飘散动态）——逍遥失重美学（飘散/消逝），与需要用力/蓄势释放的曲目（燃曲/战歌）相对。
> **标杆**：同人专辑曲目「逍遥天尊·不复逍遥」——「曾经世间第一极速，如今一步迈不出去」的逍遥丧失型角色。
> **新创作适用注记**：本 skill 用于**新有歌词创作**时建议同时满足——① **合作署名**（有歌词曲推荐联合署名，「周寻 & 云无树」式）；② **载体升维**：失重/飘散的情感内核可以取自日常，但承载意象宜升到高级/浪漫/想象力域（星空 / 时间 / 梦境 / 远方）——抽象的意象更能承载「飘散」而不落入具体叙事的重量。边界：器乐纯音乐 / 氛围 BGM 线不受此约束（本 skill 的 ambient 形态层可直接用于纯音乐线）。

---

## ⚡ 最高优先（两条硬约束，先于一切）

> **妙响线适配注记（2026-09-30）**：**妙响无 Extend**——5:20 目标在妙响线须靠**词量**（慢/中板 580+ 字 = 3 分钟+ 可靠区间，实测）**或按实际产出重定标**（接受 3-4 分钟，把「不冲的收束」放在可达时长内）。「时长跟人声行数走」机制两线相通（① 增行数照旧有效）；`[Short Instrumental Intro 8]` 类小节数定向与段标行为在妙响线**待实测**。

实测下来，这两条形态指标最决定「逍遥飘散」效果——**优先级最高，写 Style 前先确保**：

1. **时长 ≈5分20秒**：对标标杆实测（ffprobe 319s）。**声明是软目标——Suno 时长跟「人声行数」走，忽视声明时长/小节数定向**（实测：22 行 → 275s vs 41 行 → 319s，声明 5min20s 也撑不到）。Style 仍声明 `approximately 5 minutes 20 seconds`，但**真正撑长靠**：① 增人声行数（原句/关键句循环利用、加词——直击「时长跟行数走」）② **Suno Extend 兜底**（最可靠，每次 +2min，在动量上升段 Extend）。
2. **开头、结尾各 >30 秒纯器乐（无人声）**：长前奏（人声极晚进入）+ 长尾奏（人声早退、器乐收束）。用 `[Short Instrumental Intro 8]` / `[Instrumental Outro 8]` 小节数定向拉长（数字定向对 intro/outro 最有效）。人声被器乐空间包裹，是逍遥飘散的关键载体。

> ⚠️ Suno 是黑盒，时长/器乐长度是**软目标**（最高优先诱导，非硬保证）——用最强手段（声明 + 官方器乐段标记 + 小节数定向）保证，生成后实测，不达则走备选梯度（重送 / Replace Section / UVR5+DAW）。**妙响线备选**=重送／按实际产出重定标／降级接受——Replace Section（站内编辑）与 UVR5+DAW（本地后期）均不适用（无此功能 + 音频预绑定不可替换）。

## 一、核心心法：逍遥 ≠ 冲

逍遥天尊曾经世间第一极速（行字秘），想去哪去哪——这是「逍遥」：**自由自在的境界，是状态也是美学**。逍遥者**超越「冲」**（用力挣扎着够），本就是最快最自由，「冲」对他不存在。**故逍遥美学里，冲根本不该出现。**

悲剧不是「想冲冲不回去」（那还在用力的执念），而是 **「不复逍遥」**——曾经不需要冲的自由者，如今被困（造了最快速度却一步迈不出去），自由本身变成囚笼。

| | 用力 / 挣扎（冲） | 逍遥（失重 / 飘散） |
|---|---|---|
| 声音 | strain / reach / push（够、冲） | drift / dissolve / float（飘、散） |
| 高潮 | 冲上去 / 冲但失败 | **不冲的高潮**（飘散的浓） |
| 典型 | 燃曲、战歌 | 逍遥丧失、自由变囚笼（本 skill） |

**判断**：需要用力/蓄势释放（燃曲/战歌）的曲目不适用本 skill；本 skill 只服务于失重/飘散。

**第一性原则·不冲**：这首歌里不该有「冲」——声音出现 strain/reach/push 就是用挣扎玷污逍遥（**形式即内容**：连「不冲」的声音选择都服务于「逍遥丧失」的情感）。**禁用** `strain` / `reach for` / `push upward` / `falling short`（都是冲）；**改用** `drift` / `dissolve` / `fade` / `float` / `weightless` / `let go`（失重飘散）。

---

## 二、三尺度飘散（是什么）

同一「逍遥丧失」在三个尺度演绎，三者同构——本质都是逍遥的飘散/消逝：

| 尺度 | 声音行为 | 角色处境 |
|------|---------|---------|
| **句** | 极慢极拖 + 句间长空白（短句独立换行） | 曾经流畅，如今迟滞 |
| **段** | 飘散失重——在曾经明亮处飘散消逝，**不再用力够**（非 strain） | 曾经轻松触及，如今飘散 |
| **曲** | 不冲的高潮（飘散的浓）→ 释然收束（一声笑/叹息，回归逍遥姿态） | 逍遥丧失，释然 = 不必再冲 |

> 释然收束把全曲从「丧失」翻转到「回归逍遥」：不是冲不动的认输，是逍遥者不必再冲的解脱。

## 三、Suno 落地（怎么做）· 含妙响对应物

> **妙响对应物（2026-10-01 适配）**：三尺度手法均为「声音指令」层，可迁入妙响 Style 自然语言指令（妙响 Style 无过滤器，`drift`/`dissolve` 类动词直接写入）；差异点——① **声线**：妙响为显式指定（注入模板「人声用 X」+ 音色池），非 Suno 的自由分配；② **段标**：`[Short Instrumental Intro]` 类小节数定向的妙响识别行为**待实测**——优先用时长锚句 + Style 自然语言描述器乐段；③ **时长**：按顶部注记（词量 580+ 或按实际产出重定标）。换行/短句/材质层（reverb/pad/慢 BPM）两线通用。

**句尺度**：短句 + 每句独立换行（Suno 每行=一乐句，短句字少→句间过门大，最可控的抓手）；`hollow chuckle between phrases` 占位撑长 + `vocals stretch words` 拖字；辅助 `very slow with long pauses`。

**段尺度**（让声音飘散，不是用力够）：
- `vocals drift and dissolve where old bright notes used to be, weightless, no longer reaching`
- `guitar floating, letting the melody go`
- 用 `drift` / `dissolve` / `fade` / `float` / `weightless` / `let go`；**禁用** `strain` / `falling short` / `reach for` / `push upward`

**曲尺度**（不冲的高潮）：
- `vocals drift up weightlessly then dissolve`（飘散的浓）——**不要** `push upward and fail`（失败的冲，仍预设冲），也不要 `soar` / `explode` / `triumphant`（成功冲上去）
- 收束：`resolution into vocals alone over silence with only fading pads and a last quiet laugh`

**材质层**（让飘散有空气，非干瘪断裂）：`spacious` + `shimmering reverb` + `soft synth pads`（人声飘散了，reverb/pad 还在弥散）；慢 BPM（~80）打底；**稀疏空间型流派**（Dream Pop / Ambient）是天然材质。四层协同——换行 × 占位 × reverb/pad × 慢 BPM，缺一不稳，**最可靠是换行 + 材质**。

## 四、形态层：ambient 结构（与飘散并列的载体）

三尺度是声音「行为」，形态层是「结构/空间」——两者协同：形态提供空间，飘散在空间里消逝。

**ambient 形态要素**（时长 / 开头结尾器乐 已提为「⚡ 最高优先」见顶部，这里讲另外两条）：
1. **短句不砍词**（最重要）：短句化 = 每行字少（句长 3-7 字），**≠ 歌词总量少**。标杆 40 行/304 字，靠短句 + 器乐段 + 长时长腾空间，不靠砍词。反模式：砍到 10 行被纠偏；正解 = 保词量 + 重度短句化（看字数不看行数）。
2. **段落间官方器乐段标记**（非 `(mm)`）：间奏用 `[Instrumental Break]`；开头/结尾的 `[Short Instrumental Intro]` / `[Instrumental Outro]` 见 ⚡ 最高优先。

---

## 五、适用场景

**适用**（曾经逍遥/自由/巅峰，如今丧失/被困，本性不冲）：逍遥丧失型、迟暮英雄末路（非挣扎型）、自由变囚笼。
**不适用**（需要冲的成功 release）：燃曲/战歌/逆天证道、蓄力型。

## 六、诚实边界（实测为判据）

- 机制是设计层诱导，非保证（Suno 黑盒，`long pauses` / `drift` 执行不稳定）。
- 标杆**已生成实测**（2026-08，ffprobe 319s/5min20s，大段器乐 + 稀疏人声 + 40 行短句）：**形态层机制有效**（句间长空白 / 稀疏人声 / 大段器乐 / 开头结尾无人声 ✅）。
- ⚠️ **飘散动态（drift 替代 strain）尚待实测**——v0.3 基于美学校准，需新 Style 生成验证。生成后听：句间长空白？中段飘散（非挣扎够）？高潮不冲？开头结尾 ≥30s 器乐？失败走备选梯度（重送 / Replace Section / UVR5+DAW）。
- ⚠️ **妙响线待实测**：drift 动效与头尾器乐段在妙响的生成行为未实测（注记见顶部与 §三）——生成后按听感核验；失败仅可重送／按实际产出重定标／降级接受（无后期补救）。

## 七、边界与辨异

本 skill **只管声音本体**（飘散动态、形态结构）；角色设定、情绪基调、歌词手法属于各自的上游环节，不在本 skill 范围。

**与「自足之淡」美学（宋韵线）的辨异**：

- **逍遥的淡＝「丧失后的淡」**：减法来自失去——情感底色＝悲／无力，声音有飘散失重感（本 skill）。
- **宋韵的淡＝「自足的淡」**：减法来自自觉选择——情感底色＝从容／温，声音有日常的暖。
- 声音手段可共用（慢／稀／飘），**情感底色必须分开**——别把宋韵写成丧，别把逍遥写成小清新；**同曲混用＝两条线都归因不清**（多变量同轮不归因）。

---

_核心：三尺度飘散（句/段/曲）让声音成为「不复逍遥」的证词——逍遥者超越冲，声音失重飘散、消逝，不挣扎。实测为判据。_
